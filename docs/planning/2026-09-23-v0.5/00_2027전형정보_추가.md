# 2027학년도 전형 정보 — 첫 페이지 v0.5

작성일: 2026-09-23 · 화면 및 데이터 기획

## 사용자 결정

대학·학과 제목 오른쪽의 여백에 **2027학년도 전형 정보**를 표시한다. 모집군과 선발인원을 먼저 제공하고, 추후 추가 선발인원과 최종인원을 갱신한다.

사용자가 말한 추가 선발인원은 **수시 이월을 포함한 모집인원 변경분 전체**다. 감원도 표현할 수 있도록 화면 명칭은 ‘추가·변경 인원’, 값은 +4명·−2명·0명처럼 표시하는 안을 반영했다.

## 배치와 공개 범위

- 왼쪽: 대학명·학과명·전형 구분.
- 오른쪽: ‘2027학년도 전형 정보’와 모집군 / 선발인원 / 추가·변경 인원 / 최종인원.
- 아래: 기존 4개년 입시결과와 합격권·상위 70%의 환산점수·자체 누적.
- 좁은 화면: 2027 정보를 학과 제목 아래, 과거 결과 표 위로 배치.
- 일반가입자와 유료가입자 모두 이 전형 정보를 조회한다.
- 각 모집단위·전형에 대응하는 2027 실제 모집행을 연결한다. 복수 모집군·전형은 임의 합산하지 않는다.

2027은 이번 전형 정보 영역의 적용 학년도다. 과거 입시결과 조회창의 4개 학년도 확정을 뜻하지 않는다. 시안의 과거 2023~2026 및 모든 대학·인원은 가상 예시다.

## 인원 정의

| 표시 항목 | 의미 | 갱신 기준 |
|---|---|---|
| 모집군 | 해당 2027 모집행의 모집군 | 공식 모집요강 및 정정 공지 |
| 선발인원 | 기준으로 지정한 모집요강 버전의 최초 인원 | 기준 출처를 고정하고 변경 이력 보존 |
| 추가·변경 인원 | 기준 인원 대비 현재까지 확인된 전체 순증감 | 수시 이월·증원·감원·기타 정정 포함 |
| 최종인원 | 대학이 최종 확정해 발표한 모집인원 | 공식 최종 발표 및 후속 정정 |

이 영역의 인원은 모집 예정·확정 인원이다. 실제 합격자 수·등록자 수를 의미하지 않는다.

초기에는 선발인원과 모집군을 표시하고, 추가·변경은 ‘확인 전’, 최종은 ‘확정 전’으로 표시한다. 변경 공지가 검수되면 변경분을 반영하며, 최종 발표 전에는 중간 합계에 ‘최종’ 이름을 붙이지 않는다. 미확인·미공개는 null과 상태로 구분한다. 0명은 실제 0이 확인된 경우에만 표시한다.

## 변경 이력과 검증

1. 기준 모집인원의 출처·자료 기준일·버전을 고정한다.
2. 같은 학년도·모집단위·전형·모집군에 대한 공식 수정 자료를 연결한다.
3. 변경 공지가 누적 총인원을 싣는지, 직전 대비 증감만 싣는지 구분한다.
4. 동일 공지의 중복 수집·수정본 때문에 변경분이 두 번 합산되지 않도록 원본 사건과 버전을 관리한다.
5. 최종 발표 후 같은 기준에서 ‘선발인원 + 순증감 = 최종인원’을 대조한다.
6. 불일치가 있으면 검토 필요 상태로 남기고 임의로 최종인원이나 변경 이력을 맞추지 않는다.

최초 34명, 전체 순증감 +4명, 공식 최종 38명이라는 관계를 표시할 수 있다. 감원이라면 44명, −2명, 42명처럼 표현한다. 이는 화면 설명용 예시다.

최초와 최종 인원만 확보했다면 그 차이를 전체 순증감으로 산출해 산출 근거를 기록할 수 있다. 수시 이월과 다른 변경의 세부 내역은 근거가 있을 때만 분해한다. 조건부 이월 선발·기준 인원 미공개는 0으로 치환하지 않는다.

2027 모집정보의 현재 버전과 과거 결과 행의 당시 모집군·인원은 각 학년도 자료로 유지한다. 자료 출처·기준일은 기존 ‘자료 기준과 출처’ 상세 영역에 연결한다.
