과거 결과 헤더에는 2411·2311·2211·2111 등의 코드가 있다. 이를 그대로 입학 학년도로 저장하지 않고 수능 시행 시점과 적용 학년도 정의를 확인해야 한다.

이번 확인은 표시 항목의 구조 확인이다. 원본 ‘합격권’이나 ‘상위70%’의 모든 값이 대학의 공식 최종등록자 70% 점수와 같다고 검증한 것은 아니다. 타사 값을 자체 산출 누적으로 이름만 바꾸지도 않는다.

사용자는 두 기준을 구분해 모두 제공하기로 확정했다. 공개 결과에는 합격권과 상위 70% 각각의 점수·자체 누적·상태·근거를 별도로 보존한다. 공식 70% 지점, 상위 70% 집단 평균, 업체 추정 합격권을 하나의 지표로 합치지 않는다. 한 기준에 점수 근거가 없으면 타사 누적만 역산해 검증된 환산점수인 것처럼 게시하지 않는다.

## 2. 한 행의 기준

내부 식별 단위는 다음과 같다.

‘입시결과 학년도 + 학교 + 실제 모집단위 + 전형 + 모집군 + 입시결과 지표 기준’

화면에는 간결한 대학·학과 묶음과 4개년 표를 보여 주지만, 내부에서는 복수 전형·모집군과 지표 기준을 보존한다. 학과명 변경·통합·분리는 기존 학교별 4개년 공식 모집표 검수 결과에 근거해 연결한다. 연결 미확인 행을 임의로 같은 학과의 과거 결과로 붙이지 않는다.

최종 4개년 범위는 서비스의 조회 창으로 고정하고 각 학교의 결측을 표시한다. 학교마다 값이 있는 네 연도를 임의로 골라 같은 ‘최근 4개년’이라고 표시하지 않는다.

## 3. 기본 항목과 내부 근거

| 기본 표시 | 저장할 의미 | 필수 근거 |
|---|---|---|
| 학년도 | 입시결과 대상 학년도 | 시험 시행 연도·공표일과 구분 |
| 대학·학과 | 당시 모집행과 화면 그룹의 연결 | 당시 명칭·전형·통합/분리 관계 |
| 모집군 | 해당 결과 학년도의 모집군 | 해당 학년도 공식 모집표 |
| 선발 인원 | 표시할 인원과 그 종류·기준 시점 | 계획/최종 모집/실제 선발/등록 구분 |
| 정시 환산점수 | 선택한 결과 지표의 점수 | 최종등록자 등 집단, 70% 지점·합격권 등 정의, 만점·해당 연도 규칙 |
| 자체 누적백분위 | 해당 점수와 호환되는 분포에서 산출한 비율 | 비교집단·분포 학년도·모델/배포 버전·동점 정책 |

출처·점수 만점·기준일·지표 정의는 별도 기본 수치 열을 늘리기보다 상세 설명으로 제공한다. 근거가 없다는 상태를 화면에서 숨기지는 않는다.

‘모집군 및 정원’이 현재 학년도 기준일 수 있으므로 하나의 AC/AD 값을 과거 4년 모두에 반복 적용하지 않는다. 기존 4개년 모집표에서 연도별 값을 가져온다. 미공개·이월 대기·미확인 인원은 실제 0으로 저장하지 않는다.

## 4. 자체 누적값 생성

1. 표시할 입시결과 지표와 실제 점수 체계를 확인한다.
2. 동일 학년도·동일 대학 환산 규칙·같은 비교집단에 대한 검증된 분포를 찾는다.
3. 결과 점수의 엄격 상위·동점 포함 비율을 계산하고 표시 대표값 정책을 적용한다.
4. 원 점수·출처와 자체 추정값·분포 버전을 함께 보존한다.
5. 공개 검수된 결과 행만 일반 조회 자료로 발행한다.

70% 지점이라는 말은 입시결과 집단 내 지표 정의다. 화면의 ‘상위 2.5%’ 같은 누적백분위는 응시 비교집단에서의 위치다. 두 값의 분모를 구별한다.

합격권을 우리 모델로 추정하는지, 공식 결과에 근거해 정의할지는 아직 정하지 않았다. 합격권이라는 이름을 최종 합격자의 실제 최저점이나 특정 합격 확률로 자동 해석하지 않는다.

입시결과가 평균 백분위나 평균등급뿐이면 대학 환산점수로 정확히 복원되지 않을 수 있다. 이 경우 환산점수·자체 누적을 임의 생성하지 않고 원 지표를 보존하며 미산출 사유를 기록한다.

전년도 점수를 올해 규칙으로 변환하거나 4개년 점수를 모두 올해 점수처럼 표시하지 않는다. 연도별 반영식·만점 변화가 있으면 설명한다. 누적백분위를 비교할 때도 연도와 비교집단 정의가 달라지는 점을 알려 준다.

## 5. 미공개·미산출 표현

- 점수 공개·누적 모델 미검증: 점수 표시, 누적 ‘산출 준비’.
- 학과 신설·대응 과거 모집행 없음: ‘해당 없음’.
- 공식 결과 미공개: ‘미공개’.
- 자료 수집 또는 검수 미완료: ‘확인 중’.
- 모집인원 실제 0: 출처가 확인된 경우만 숫자 0.
- 추정 누적의 동점 구간: 모델 오차 범위와 구분.

미산출 값을 0점·0%로 표시하지 않는다. 4개년의 일부가 없어도 결과 존재 여부를 그대로 보여 준다.

## 6. 공개 범위와 보안

일반가입자는 승인된 과거 결과 행을 검색할 수 있다. 자신의 성적이나 임의 점수로 이 API를 호출해 새 누적값을 얻을 수는 없다.

응답에는 검색한 행의 기본 항목과 필요한 지표 설명·출처만 보낸다. 전체 누적표, 원본 학생 표본, 모델 코드·계수, 개인 분석 결과는 포함하지 않는다.

자료를 회원 화면에 제공하면 해당 표시값의 복제 가능성은 남는다. 이 설계는 핵심 분포 전체와 개인 분석 기능을 분리하면서 서버 측 조회 제한으로 과도한 수집을 줄이는 구조다.
