## 화면에 연결할 방식

대학·학과별 결과 묶음 아래에 학년도를 배치한다. 합격권과 상위 70%를 각각 상단 헤더로 두고 각 기준 아래 환산점수·자체 누적을 표시한다. 4개년은 동일 조회창을 사용한다. 한 학년도에 모집행이 여러 개면 offerings를 여러 행으로 보존한다.

history.mock.json은 2개 가상 대학·학과에 각 4개 학년도를 담는다. 2023~2026은 설명용 범위다. 대학·학과명, 군·인원, 점수·누적 등 모든 예시값은 실제 자료가 아니다. 운영 서비스의 학년도, 가격, 기간, 인원 정의를 확정하지 않는다.

cumulative_percentile.fraction에 0.038이 있으면 ‘상위 3.80%’로 표시한다. 값이 null이고 상태가 pending_model이면 ‘산출 준비’로 표시한다. 상위 70%라는 결과 기준과 전체 비교집단의 상위 비율을 구별한다.

## 권한 확인 범위

회원 상태 예시는 메뉴·버튼 상태를 검토하기 위한 자료다. 브라우저의 표시 상태를 바꾸는 것은 이용권한을 부여하지 않는다. 서버는 일반 자료 조회와 유료 개인 계산을 별도 검사해야 한다.

기존 [v0.3 프레젠테이션 계약](../../2026-09-23-v0.3/handoff/README.md)은 범용 조회·계산 구조의 이력이다. 이번 회원 구분과 첫 페이지의 복수 결과 기준에는 v0.4를 우선한다. 실제 운영 구현 시 하나의 명세로 통합하고 서버 검증을 수행한다.

## 검증의 한계

JSON 구조·4개년 배열·기준별 점수/누적·결측 표기와 권한 표의 일관성을 점검한다. 실제 입시값 검증, 모집표 전수 대조, 결제 연동, 서버 인증·권한 차단 테스트를 완료했다는 의미는 아니다.
