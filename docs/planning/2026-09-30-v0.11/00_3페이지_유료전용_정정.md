# 3페이지 대학 가능성 보기 — 유료가입자 전용 정정

2026-09-30 사용자 명시 정정. ‘1페이지와 같다’는 대학명·학과명을 입력하는 기본 검색 구성을 뜻한다. 접근 권한이 같다는 뜻이 아니다. 3페이지의 일반가입자 기본 검색을 허용했던 v0.10 해석을 폐기하고, 이 문서와 v0.11 계약을 현재 기준으로 한다. 이전 파일은 이력으로 보존한다.

## 확정된 권한

| 화면·기능 | 일반가입자 | 유료가입자 |
| --- | --- | --- |
| 1페이지 4개년 입시결과 조회 | 이용 가능 | 이용 가능 |
| 전체 상위 누적백분위 확인 | 이용 가능 | 이용 가능 |
| 3페이지 대학 가능성 보기 — 검색·결과·상세 | 이용 불가 | 이용 가능 |
| 3페이지 내 환산점수·개인 판정 | 이용 불가 | 성적 및 분석 근거가 있으면 제공 |
| 4페이지 유리한 대학 찾기·와일드카드 | 이용 불가 | 이용 가능 |

일반가입자에게는 3페이지 검색창·필터·검색 결과·검색 건수·모집단위 상세·핵심 지원 학교 목록을 제공하지 않는다. 직접 주소를 열어도 유료 이용 안내만 보이도록 한다. 일반가입자의 입결 조회는 기존 1페이지에서 제공한다.

## 유료가입자의 검색 구성

1페이지와 같은 대학명·학과명 입력 구조를 유지한다. 대학명만, 학과명만, 또는 둘을 함께 검색할 수 있다. 서비스 범위 내에서 추천 밖 대학, 지원 조건 미충족 전형, 분석 자료 미확인 모집행도 직접 찾아 상세를 확인할 수 있다. 성적에 따른 추천 여부는 유료 사용자의 검색 대상을 자동으로 제한하는 조건이 아니다.

유료가입자의 검색 권한과 성적 입력 여부는 구분한다. 성적이 없으면 해당 학과의 개인 분석 영역에 성적 입력 안내를 표시하며, 성적이나 모형의 결과를 만들어 내지 않는다. 도전학교·핵심학교·여유 후보와 오른쪽 와일드카드 구성은 별도 4페이지에 유지한다.

## 3티어 권한 적용

- 화면: 일반가입자 상태에서는 3페이지 입력·검색·상세 이벤트를 무시하고 결과와 건수, 상세, 선택 목록을 지운 뒤 유료 안내를 표시한다. 유료 상태에서 일반 상태로 전환해도 이전 결과가 화면에 남지 않는다.
- 서버: 3페이지 검색·건수·상세 및 개인 분석 요청 모두 인증과 활성 유료 권한을 먼저 확인한다. 일반가입자 요청은 `403 paid_required`로 응답하고 검색 결과·건수·상세를 포함하지 않는다. 1페이지 조회 권한이나 브라우저의 임의 가입자 값으로 우회하지 않는다.
- 데이터: 1페이지에 허용한 입결 응답과 3페이지 유료 응답을 구분한다. 유료 확인 후에는 모집 카탈로그를 기준으로 사용자가 검색한 모집행을 조회하며, 추천 결과가 없다는 이유로 누락하지 않는다. 개인 분석은 권한·성적·리포트 소유자 검증 후 제공한다.

3페이지 검색 API 계약은 `/api/v1/possibility/offerings`이며, 1페이지 공용 조회 엔드포인트를 그대로 유료 분석 권한으로 사용하지 않는다. 실제 유료 여부는 운영 서버가 검증해야 한다. 미리보기의 가입자 전환 선택 상자와 sessionStorage 값은 가상 화면 검증용이며 인증·결제 수단이 아니다.

현재 산출물은 가상 데이터 화면과 서버 계약이다. 실제 인증·결제·API 및 DB 접근 제어, 전국 입시 데이터·환산 엔진 연결, 브라우저 시각 검수는 완료하지 않았다. 1페이지와 2페이지의 기존 정책, 원본과 현재 모집 매핑은 변경하지 않는다.
