# 3번 페이지 협업 자료 v0.7

먼저 [핵심 기획](../00_환산유불리_핵심기획.md)과 [산출 명세](../01_환산유불리_산출명세.md)를 읽는다.

- [candidate-contract.json](candidate-contract.json): 회원 권한·결과 필드·비교 가능 조건·외부 이동 정책.
- [candidate.mock.json](candidate.mock.json): 화면 검토용 가상 대학·학과·수치. 운영 자료가 아니다.
- [검증 기록](../검증_기록.json): 확인한 내용과 미구현 범위.

3번 페이지 관심 목록은 운영 구현 시 2번 페이지와 같은 서버 목록을 사용한다. 현재 대화 시안은 로컬 선택 동작이며 다른 시안과 실제 계정 저장소를 연결하지 않았다.

왼쪽 2/3 기본 대학 목록 + 오른쪽 1/3 특수계열을 유지한다. 특정 대학에 하나의 환산식이 있는 것처럼 일반화하지 않는다. 카드의 점수는 표시된 환산 규칙 묶음에만 해당한다. 일반가입자 응답에는 개인별 대학 결과를 포함하지 않는다.

진학사로의 연결은 사용자가 관심 모집단위 목록을 확인한 후 직접 검색·등록하는 방식이다. 공식 가이드 링크를 확인했으나 제휴·자동등록·API 연동은 구현하지 않았다. 예시에는 실제 성적 자동 전송이나 외부 계정 입력 기능이 없다.

2027/2026 표시는 가상 화면 시나리오다. 첫 서비스 학년도·실제 입결 연도 범위는 미정이다. 4개년 상세는 설계 대상이며 시안은 한 해를 예시로 보여 준다.
