# 환산 유불리 중심 대학 탐색 기획 v0.7

작성일: 2026-09-23. 사용자 확정 요구와 구현 제안을 구분한다. 원본 및 이전 버전은 보존한다.

## 서비스의 핵심

학생의 통합 누적백분위로 검토할 대학·모집단위를 넓게 찾고, 비슷한 후보들 사이에서 학생의 과목별 강점이 잘 반영되는 대학을 골라 주는 컨설팅 리포트의 웹 서비스다. 대학별 환산점수, 환산에 따른 상대 위치 변화, 과거 학과별 입결 비교를 함께 제공한다.

학부모는 우리 서비스에서 후보를 추린 뒤 외부 진학사 모의지원에 직접 등록해 확인한다. 사용자 답변으로 이 흐름이 확정됐다. 우리 서비스의 관심 목록 저장은 진학사 등록 완료를 뜻하지 않는다.

## 확정된 화면과 흐름

1. 1번 페이지: 개인 성적 없이 4개년 입시결과 조회. 합격권·상위 70%와 2027 모집정보를 유지한다.
2. 2번 페이지: 개인 성적·통합 누적백분위 리포트. 유료회원은 선택 대학의 분석을 포함해 출력한다.
3. 3번 페이지: 환산 유불리를 비교하고 모의지원할 후보를 고른다. 데스크톱 본문은 왼쪽 2/3 기본 대학 목록, 오른쪽 1/3 간호·보건·교육 와일드카드다.
4. 3번 페이지에서 선택한 모집단위가 2번 페이지와 동일한 서버 관심 목록에 저장된다. 이 목록으로 진학사 검색·등록에 필요한 대학명·캠퍼스 표시·모집단위·전형·모집군을 정리한다.

무료회원은 1번 페이지와 본인 통합 누적까지 이용한다. 3번 페이지의 개인별 대학 비교·와일드카드·관심 목록은 유료 기능이다. v0.6의 회원 정책을 유지한다.

## 왼쪽 2/3: 기본 대학 목록

대학을 묶어 보여주되 계산 단위는 해당 학년도의 실제 모집단위·전형·모집군이다. 같은 대학에서도 반영 방식이 다른 모집단위를 하나의 점수로 합치지 않는다.

각 대학 영역에 다음을 표시한다.

- 비교 대상 모집단위 또는 같은 환산 규칙을 쓰는 묶음.
- 나의 대학별 환산점수와 만점, 반영 학년도.
- 비교집단이 일치하고 검증된 분포가 있을 때 환산 후 상대 위치와 유불리 근거.
- 유리한 이유: 수학 반영 비중, 탐구 반영 방식, 영어 감점, 선택과목 가산점 중 실제 계산으로 확인된 내용.
- 과거 합격권 기준 이상인 학과와 상위 70% 기준 이상인 학과를 구분한 목록. 비교 가능한 모집단위 수와 자료 부족 수를 함께 표시한다.
- 학과별 입결 펼치기, 핵심 지원 학교에 담기.

사용자가 말한 ‘어느 학과까지 합격했는지’는 화면에서 ‘내 점수와 비교한 과거 입결 범위’로 표현한다. 과거 기준 이상은 올해 합격을 뜻하지 않는다. 학교 전체에 고정된 학과 서열을 만들어 한 학과 아래의 모든 학과를 가능하다고 표시하지 않는다.

## 오른쪽 1/3: 특수계열 와일드카드

간호·보건·교육 모집단위를 같은 환산·입결 검증 절차로 별도 탐색한다. 기본 대학군 밖에서도 환산 결과가 비교 가능한 후보를 찾을 수 있게 별도 검색 경로를 둔다. 항상 오른쪽을 채우기 위해 자격 미충족·근거 부족 후보를 추천하지 않는다.

각 카드에는 대학·모집단위, 계열, 모집군, 내 환산점수, 과거 입결과의 비교, 발견 이유, 확인할 지원 조건과 핵심 지원 학교에 담기를 둔다. 자격 확인이 필요한 후보는 추천 완료로 표시하지 않고 조건 확인 항목으로 분리한다. 자격 미충족이면 후보에서 제외한다.

교육 계열은 학과 이름만으로 교원 자격 취득 경로를 추정하지 않는다. 간호·보건도 관련 자격·면허에 관한 설명을 넣을 경우 공식 학과·전형 자료를 확인한다. 이번 단계에서 특정 학교의 자격·면허 정보를 확정하지 않았다.

기존 수집 범위는 일반대학·교육대학이다. 보건 와일드카드를 이유로 전문대학을 자동으로 서비스 범위에 추가하지 않는다.

## 모의지원 서비스 확인 흐름

‘핵심 지원 학교에 담기’ → ‘핵심 지원 학교’ → 모의지원 서비스에서 확인 → 이용자가 직접 검색·모의지원 → 우리 리포트에서 후보를 다시 검토한다.

목록에는 검색용 대학·학과·전형·모집군, 우리 서비스의 추천 이유, 점수·입결 기준일을 남긴다. 진학사 내부 식별자·모집단위별 검색 링크는 검증 전 만들지 않는다. 외부 계정 입력, 성적 자동 전송, 모의지원 자동 등록은 현재 범위에 포함하지 않는다. 진학사 등록 여부를 사용자가 기록하는 기능은 후속 후보이며 자동 확인된 상태와 구별한다.

진학사 공식 이용 가이드에서 성적입력 → 모의지원 → 합격예측 리포트 흐름을 확인했다. 안내 확인은 제휴나 API 연동의 근거가 아니다. [진학사 정시 합격예측 이용 가이드](https://www.jinhak.com/jh/high3/regular/manual), 확인일 2026-09-23.

## 화면 명세

- 페이지 제목: 내 성적에 유리한 대학 찾기.
- 상단: 적용 학년도·총점·통합 추정 상위 비율·기준일, 핵심 지원 학교 버튼.
- 데스크톱: 본문 grid 2fr / 1fr. 왼쪽 대학 목록, 오른쪽 와일드카드. 두 영역 모두 첫 화면에 보인다.
- 대학 항목: 환산 규칙 묶음, 환산점수, 같은 집단에서의 환산 유불리, 이유, 합격권/상위70% 기준별 학과 수.
- 학과 펼침: 실제 모집단위·전형·군과 결과 학년도별 합격권/상위70%를 분리 표시. 비교 상태·기준일·관심 목록 동작.
- 예시는 2026 입결 한 해를 사용해 밀도를 검토한다. 운영 상세는 4개년을 제공하고, 누락 연도를 존재하는 것처럼 채우지 않는다.
- 폭이 부족하면 대학 목록 다음에 와일드카드를 배치한다. 표는 핵심 항목을 줄바꿈해 작은 화면에서도 읽을 수 있게 한다.
- 일반가입자: 자신의 총점·통합 누적은 유지하고 대학 개인 분석 부분에 유료 기능 안내를 표시한다. 실제 서버는 결과 필드를 보내지 않는다.
- 빈 후보, 지원 자격 확인 필요, 입결 비교 불가, 분포 미승인 상태를 각각 표현한다.
- 예시의 ‘목록에서 빼기’는 화면 내 가상 선택만 바꾸는 동작이며 프로젝트 파일 삭제와 무관하다.

## 확정하지 않은 사항

- 첫 서비스 학년도·대학 범위와 4개년 결과의 정확한 학년도 창.
- ‘비슷한 학교군’을 만드는 거리·범위 및 선호 전공·지역의 우선순위.
- 자체 통합 및 대학별 결합 분포의 검증·발행, 유불리 차이를 표시하는 최소 기준.
- 전년도 입결을 올해 기준에 연결하는 검증 방법과 외부 링크의 실제 서비스 경로.
- 가격·결제, 저장·보관기간, 운영 기술 스택.

화면 예시는 가상 대학과 가상 수치다. 실제 학교 추천이나 합격 판정 결과가 아니다. 실제 학교별 4개년 모집표 검수는 이번 화면 기획 작업에 포함되지 않았다.

## 최신 화면 문구 확정

사용자 정정에 따라 목록 제목은 ‘핵심 지원 학교’, 선택 버튼은 ‘핵심 지원 학교에 담기’, 외부 확인 동작은 ‘모의지원 서비스에서 확인’으로 통일한다. 특정 외부 업체의 등록용 도구처럼 보이는 문구를 화면에 쓰지 않는다. 문서의 공식 출처 표기는 화면 문구와 구분한다.
