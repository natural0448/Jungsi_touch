# 전체 가능성 3페이지 · 유리한 대학 찾기 4페이지 — v0.9

2026-09-30 사용자 정정 반영. 전체 대학·학과 가능성 보기는 3페이지, 이전 3페이지였던 유리한 대학 찾기는 4페이지로 분리한다. 같은 페이지의 두 탭으로 묶지 않는다. 작업을 시작한 디렉터리 날짜는 2026-09-29이며 최종 화면 구성은 이 문서를 따른다.

## 네 페이지의 역할

| 페이지 | 화면 | 목적·범위 |
| --- | --- | --- |
| 1 | 4개년 입시결과 | 자신의 성적 없이 대학·학과별 과거 입결 확인 |
| 2 | 내 성적 리포트 | 성적 입력·전체 누적 확인 및 선택한 대학·학과의 컨설팅 리포트 |
| 3 | 전체 대학·학과 가능성 보기 | 서비스 대상 모든 정시 모집단위를 검색하고 내 성적 기준의 개별 검토 결과 확인 |
| 4 | 유리한 대학 찾기 | 환산에 유리한 대학을 도전학교·핵심학교·여유 후보로 탐색하고 와일드카드 검토 |

3·4페이지의 개인별 가능성·추천은 기존 정책대로 유료 기능이다. 일반가입자의 1페이지 입결 조회 및 2페이지 전체 누적 확인 정책은 유지한다. 이번에는 3·4페이지를 구현한 가상 화면만 제공하며, 기존 1·2페이지 파일을 재구현하지 않았다.

## 3페이지: 전체 대학·학과 가능성 보기

대학명 또는 학과명을 검색한다. 지역·모집군·검토 결과로 범위를 좁힌다. 대학을 먼저 묶어 보여주고 실제 학과·전형·모집군으로 펼친다. ‘가온 경제’처럼 대학명과 학과명을 함께 입력하면 두 조건에 맞는 모집행만 보여준다. 검색 결과의 대학 수와 모집단위 수를 구분한다.

추천 목록에 없는 대학, 추천 범위 밖의 학과, 지원 조건 미충족, 자료 미확인도 각각 표시한다. 검색 자체를 기존 추천 후보 집합으로 제한하지 않는다. 조건에 맞는 학과가 없으면 검색 결과 없음으로 안내하며, 이를 지원 불가로 표현하지 않는다. 학과명으로 검색한 뒤 ‘이 대학의 전체 모집단위 보기’를 눌러 같은 대학의 다른 학과를 확인할 수 있다.

- 도전 학과 / 핵심 검토 / 여유 후보: 모집단위별 비교 결과. 합격 확률을 뜻하지 않는다.
- 추천 범위 밖: 현재 추천 정책 범위 밖이며 합격 불가능을 확정한 것이 아니다.
- 확인 필요: 자료·공식 규칙·지원 자격 등의 확인이 필요하다.
- 지원 조건 미충족: 해당 학생이 해당 전형의 확인된 지원 조건을 충족하지 않는 경우다.

‘전체’는 서비스 범위의 전체 모집단위를 뜻한다. 기존 합의에 따라 실기 반영 전형은 제외한다. 예체능 학과는 명칭만으로 제외하지 않는다. 운영 카탈로그는 수집 대상 명부·검수된 실제 모집행과 연결하고, 범위·기준일·수록 및 미확인 상태를 제공해야 한다.

## 4페이지: 기존 유리한 대학 찾기

기존 도전학교·핵심학교·여유 후보와 대학별 학과 펼침을 유지한다. 학과별 도전·핵심·여유 판단은 학교의 탐색 분류와 별개다. 왼쪽 2/3는 기본 대학 목록, 오른쪽 1/3은 간호·보건·교육 와일드카드다. 모바일에서는 세로로 배치한다.

내 환산점수·해당 환산 기준의 내 누적·과거 합격권·상위70%·올해 예상 기준·추천 이유를 모집행별로 표시한다. 여러 반영식이 있는 대학은 학과별 점수를 별도로 사용한다.

## 페이지 간 선택과 3티어 구현

3·4페이지 모두 동일한 ‘핵심 지원 학교’ 목록을 사용한다. 실제 저장 키는 사용자 리포트 × 학년도 × 실제 모집행 PK다. 기본 목록·전체 검색·와일드카드에서 같은 모집행을 여러 번 조회해도 선택은 한 건이다. 사용자 선택 변경만 선택 집계에 반영하며, 검색·펼침·페이지 이동은 추천 또는 선택 이벤트로 간주하지 않는다. 추천 집단은 추천 엔진의 별도 결과 집합을 기준으로 한다.

- 화면: 3페이지 전체 검색, 4페이지 추천 탐색을 서로 다른 URL로 제공한다. 결과 표시와 필터·선택 UI를 담당한다.
- 서버: 권한과 리포트 소유자를 확인하고 실제 모집행별 공식 환산·입결·예측을 비교한다. 전체 검색은 추천 후보에 포함되지 않은 모집행도 조회한다. 운영 환경에서는 정렬·페이지네이션·조건별 개수와 판정 버전도 서버가 제공한다.
- 데이터: 검수된 학교·캠퍼스·모집단위 PK를 재사용하고 환산 규칙, 누적곡선, 입결 정의, 올해 채택 기준, 추천 및 선택 이력을 관리한다. 학교 평균이나 추천 그룹을 개별 학과 판정에 복사하지 않는다.

실제 규칙표·모델 파라미터·비공개 전체 자료는 브라우저에 넣지 않는다. 무료 제한도 API 단계에서 적용한다. 현재 HTML의 유료/무료 전환은 화면 검토용 기능이다.
