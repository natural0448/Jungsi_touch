# 대학 매핑 이후의 입결 수집·자체 누적·예측 운영

작성일: 2026-09-27. 최신 사용자 설명을 반영한 후속 기획이다. 실제 입결 일괄 수집, 대학 매핑 변경, 예측 모형 학습 또는 운영 컷 발행을 이번 작업에서 수행한 것은 아니다.

## 1. 사용자가 확정한 연결 관계

대학 매핑 → 대학어디가 입결 수집 → 학교별 산출 기준에 맞는 자체 누적백분위 → 2024·2025·2026학년도 입결 변화 분석 → 올해 이슈와 상담자의 판단을 반영한 예상 컷 → 학생별 핵심 지원 학교 제안.

- 다른 채팅에서 진행하는 대학 매핑은 모집단위별 과거 결과를 연속된 이력으로 연결하기 위한 기반이다. 해당 작업의 완료를 확인한 것처럼 표현하지 않는다.
- 입결 수집은 매핑 이후에 진행한다. 지금 단계에서 다른 채팅에 작업을 보내거나 매핑 파일을 변경하지 않는다.
- 2024·2025·2026학년도 결과를 초기 예측 분석의 3개년 이력으로 사용한다.
- 대학별 올해 이슈는 사용자가 설명하고 함께 검토하여 모델 결과에 반영한다. 단순히 모델 출력만 확정하는 운영으로 설계하지 않는다.
- 현재 페이지 기획의 2027학년도 전형 정보를 기준으로 다음 해 예측 연결을 설명한다. 대상 학년도는 데이터와 실행 기록의 명시적 필드로 둔다.
- 첫 페이지의 기존 4개년 결과 조회 범위와 이번 예측 모델의 초기 3개년 분석 창은 별도다. 조회 범위를 3개년으로 변경하지 않는다.

## 2. 매핑 결과를 입결 이력으로 연결하는 방법

모집단위별 실제 모집행과 학년도 사이의 연결 관계를 사용한다. 같은 학교의 2024~2027 요강을 묶어 대조하는 프로젝트 원칙을 유지한다.

기존 모집행 키와 연도 연결 키·관계 유형·검수 상태·근거를 받는다. 모집단위 이름만으로 새 연결을 만들어 기존 매핑을 대체하지 않는다. 학교 통합, 캠퍼스, 명칭 변경, 학과 통합·분리, 전형 및 군 변경을 구분한다.

단순 명칭 변경으로 확인된 연속 행은 연결된 이력으로 사용한다. 통합·분리·모집 대상 변경은 구조 변화로 기록한다. 통합 전 여러 학과의 70% 컷을 모집인원으로 가중평균해 통합 후의 70% 컷으로 확정할 수는 없다. 필요한 경우 추정 경로와 불확실성을 별도로 남긴다.

학교별 검토 단위는 4개년 묶음이며, 학교 안의 결과·예측 저장 단위는 실제 모집단위·전형·모집군과 환산 규칙이다. 다른 전형이나 군의 결과를 하나의 대학 컷으로 합치지 않는다.

## 3. 대학어디가에서 수집할 값의 의미

어디가의 수능 용어 안내에서 환산점수는 대학별 반영 방식에 따라 산출한 점수이며, 50%·70% 컷은 최종등록자 중 해당 순위의 수능 환산점수로 설명된다. 최종 합격자의 최저점이나 전체 수능 응시자 중 상위 50%·70%라는 뜻이 아니다. 대학별 추가 안내와 실제 표의 지표 정의를 함께 보존한다.

수집 대상 후보:

- 결과 대상 학년도, 페이지의 평가기준 학년도, 발표·수집·기준 날짜.
- 대학 및 기존 모집행 키, 원문 모집단위·전형·군 이름, 연결 관계 버전.
- 원문 지표명과 종류: 대학 환산점수의 50%·70% 컷, 선택 공개되는 다른 컷, 평균 및 기타 공개값.
- 환산점수·만점, 영역별 백분위·영어 및 한국사 등급 등 공개된 보조 지표.
- 모집인원 최초·변경·최종, 경쟁률, 충원 관련 값과 각각의 정의.
- 원문 URL, 표·행·열 위치, 각주, 원래 표시 문자열, 정규화 값, 확인 상태.

자료가 전년도 결과를 싣는 경우 페이지 선택 학년도와 결과 학년도가 다르다. 예를 들어 확인한 2026학년도 대학 정보 페이지의 정시 결과 표에는 2025학년도 결과가 실려 있다. URL의 연도를 결과 학년도로 곧바로 저장하지 않는다.

과목별로 따로 산출된 70% 컷은 같은 한 학생의 성적표라고 가정하지 않는다. 해당 순위 학생의 영역 성적을 공개한 표인지, 각 영역에서 각각 구한 분위수인지 원문 정의를 확인한다. 평균 백분위와 대학별 환산점수도 동일한 의미의 지표로 합치지 않는다.

자료가 없거나 비공개인 결과는 결측 사유를 남긴다. 실제 0·미공개·해당 없음은 별개다. 공식 대학 자료와 포털이 충돌하면 양쪽 원문 및 정정 근거를 보존한다.

## 4. 자체 대학별 누적백분위를 만드는 역할 분담

국수탐 총점용 누적 곡선과 대학 환산점수용 누적 곡선을 구분한다. 같은 총점이어도 과목 조합에 따라 대학 환산점수는 달라질 수 있으므로, 대학별 곡선에는 그 대학의 반영 영역·비율·선택과목·탐구 변환·영어 등급 처리 등을 반영한다.

어디가의 입결은 각 대학의 과거 선발 수준에 대한 관측 근거다. 우리 자체 점수 분포·누적 곡선과 해당 학년도의 환산 규칙을 연결해 이 관측값을 자체 누적 척도로 해석한다. 기존 정시 참고 엑셀은 검증 및 보정 자료로 이어 사용하되 학년도·모집단·지표 정의 차이를 보존한다.

설계상 계산 관계는 다음과 같다.

- 학생 프로필 x의 해당 학년도 대학 환산점수: s = R(학년도, 환산규칙, x)
- 대학 환산점수의 자체 상위 누적: U(학년도, 규칙, s) = 해당 규칙으로 s 이상인 추정 비교 인원 / 비교집단 전체 추정 인원 × 100
- 과거 컷의 자체 누적: p(결과학년도, 모집단위, 지표) = U(해당 학년도, 해당 규칙, 원문 컷)

이는 산출 정의다. 대학별 추정 분포가 구축·검증되었다는 의미는 아니다. 대학의 합격자 요약 컷 몇 개만으로 전체 응시자의 점수 분포가 자동 복원되는 것도 아니다. 누적값마다 curve_version, rule_version, population_id, 동점 처리, 추정 방법 및 검증 상태를 남긴다. 비교집단이 다른 누적은 공통 척도로 보정하거나 비교 제한을 표시한다.

예전 컷을 올해 환산식에 바로 대입하지 않는다. 과거 값은 그해 규칙과 분포로 해석하고, 올해는 올해 규칙과 분포로 계산한다. 옛 환산점수 하나에서 개인의 과목별 원성적을 유일하게 역산할 수 있다고 가정하지 않는다.

## 5. 3개년 추세와 올해 예측

2024·2025·2026의 실제 공개 결과와 정규화한 자체 누적을 나란히 보며, 동일 지표의 상승·하락·변동 폭을 검토한다. 과거 관측값을 예측값으로 덮어쓰지 않는다. 원점수 척도와 만점·수능 난도·환산 기준 변경의 영향을 구분한다.

초기 후보 구조는 전년도 수준과 비교 가능한 3개년 추세에서 기본 예측을 만들고, 모집인원·모집군·환산 규칙·전형 구조의 변화와 올해 이슈를 반영하는 방식이다. 3개 연도의 관측값만으로 복잡한 추세식을 확정하거나 정해진 비율로 매년 오를 것이라고 가정하지 않는다. 모델 종류·연도 가중치·유사 모집단위 공유 방식은 자료 수집과 검증 후 결정한다.

예측 대상도 구분한다.

| 대상 | 관측 또는 산출 기준 |
|---|---|
| 과거 공개 70% 컷 | 어디가·대학 원문에서 확인한 그해 관측값 |
| 올해 예상 70% 컷 | 동일한 지표를 목표로 하는 예측값 |
| 올해 예상 합격권·하단 컷 | 목표 의미와 별도 검증 근거를 갖춘 추정값 |

70% 컷을 올해 최저 합격선으로 그대로 표시하거나 임의의 고정 보정만으로 최종 합격선을 확정하지 않는다. 합격권 하단을 추정할 때에는 근거와 범위를 따로 제공한다.

올해 실제 수능 분포가 나오기 전에는 예측 누적과 가정에 따른 범위를 관리할 수 있다. 실제 분포 및 적용 환산 기준이 확보되면 해당 대학의 올해 점수 척도로 역조회해 예상 환산점수와 함께 제시한다. 동점·계단형 구간은 유일한 소수 점수로 과도하게 정밀화하지 않고 구간 또는 정해진 역조회 규칙을 사용한다.

상위 누적은 작을수록 상위권이다. 동일 기준에서 입결 상승은 점수 상승·상위 누적 하락 방향이다. 연도마다 척도가 다른 원점수의 단순 상승을 이 방향과 혼동하지 않는다.

## 6. 학교별 이슈를 함께 반영하는 운영

학교별 검토 노트에는 다음을 기록한다.

| 항목 | 기록 내용 |
|---|---|
| 적용 범위 | 학교 전체인지 특정 모집단위·전형·군인지 |
| 이슈 | 모집인원 변화, 군 변경, 신설·통합, 반영 방식, 지원자 선호 등 |
| 근거 | 공식 확인 사실, 사용자 상담 판단, 추가 확인할 가설을 구분 |
| 예상 영향 | 지원 경쟁의 강화·완화, 예상 컷의 방향과 가능한 폭 |
| 이미 반영된 영향 | 기본 모델이나 환산 규칙 변경에서 처리했는지 |
| 공동 검토 | 사용자 설명, 확인 자료, 채택·보류 이유 |
| 변경 기록 | 기준일, 작성·검토자, 이전 값, 변경값, 모델 및 이슈 버전 |

한 학교에서 이야기된 이슈를 모든 학과에 동일한 폭으로 적용하지 않는다. 올해 모집인원 감소가 모델 입력에 이미 반영됐다면 상담 조정에서 같은 효과를 다시 중복 가산하지 않는다. 정성 의견을 근거 없이 확정된 수치 효과로 저장하지 않는다.

기본 예측값 → 이슈 반영 제안 → 사용자와 공동 검토한 최종 채택값의 세 상태를 별도로 남긴다. 운영 화면에는 최종 채택한 컷과 필요한 설명을 제공하고, 내부에는 기본값·조정 내용·근거를 보존한다. 미채택 제안을 확정 운영값으로 자동 발행하지 않는다.

## 7. 검증과 화면 연결

검증은 당시 알 수 있었던 정보만으로 이후 결과를 예측해 비교한다. 예를 들어 2026 결과를 평가 대상으로 두면 그 결과를 기본 모델 학습·곡선 보정·사후 이슈 선정에 먼저 사용하지 않는다. 현재 3개년 창에서 가능한 과거 검증의 길이는 제한적임을 기록한다.

단순 전년도 유지 기준, 모델 기본값, 이슈 반영 후 값을 같은 지표와 시점 기준으로 비교한다. 예상 범위에 실제 결과가 들어오는 비율과 예측 오차를 보며, 실제 결과가 나오면 모델 추세와 상담 조정의 기여를 나누어 확인한다. 아직 오차 성능이나 신뢰수준은 측정하지 않았다.

3페이지에서는 학생의 대학별 환산점수·자체 누적을 그 모집단위의 올해 예상 컷·과거 추세와 함께 보여 준다. 왼쪽 2/3 기본 대학·학과 목록과 오른쪽 1/3 간호·보건·교육 와일드카드 모두 같은 기준을 사용한다. 최종 행동 문구는 핵심 지원 학교에 담기 / 모의지원 서비스에서 확인을 유지한다.

## 8. 현재 산출물과 다음 입력

이번에는 사용자 결정과 모델 운영 구조를 문서화하고 공식 공개 지표 정의를 확인했다. 입결 일괄 수집, 새 예측 수치 생성, 모집단위 매핑 수정은 진행하지 않았다.

다음 단계 입력은 완료된 매핑과 검수 기록이다. 이후 같은 학교의 3개년 입결 원문을 연결해 수집하고, 지표 정의·환산 규칙·자체 누적 곡선을 검증한 뒤 학교별 추세 및 올해 이슈를 함께 검토한다. 외부 공개 자료에 없는 값과 예측 과정에서 생성한 값은 명확히 구분한다.
