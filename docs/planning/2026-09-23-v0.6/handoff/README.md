# 개인 리포트 협업 자료 v0.6

[기획](../00_개인리포트_무료유료_기획.md), [근거 재검토](../01_정시판_판별근거_재검토.md), [산출 계약](../02_통합누적_산출계약.md)을 먼저 읽는다.

- [report-contract.json](report-contract.json): 일반가입자의 통합 분석 허용, 유료 대학 분석·출력 권한과 API 초안.
- [report.mock.json](report.mock.json): 가상 성적과 일반/유료 리포트 예시. 실제 분석 결과가 아니다.
- [내부 참고 조회 코드](../../../../scripts/overall_percentile_reference_v1.py): 2026 중등진학 원본의 정확한 키 조회를 재현한다. Python 표준 라이브러리와 기존 원본 읽기 도구를 사용한다.
- [검증 기록](../검증_기록.json): 실제 확인한 범위와 운영 미구현 항목.

내부 참고 조회 코드는 공식 점수 유효성 검증·가입자 권한·실제 자체 모델을 구현한 서비스 엔진이 아니다. 과목 구성에 관계없이 같은 총점이면 같은 참고 누적을 반환하고, 학년도 불일치·범위 밖·누락 키를 거절하는 연구용 검산 도구다. 항상 자체 지표 미승인 상태를 반환한다.

가상 화면의 상위 2.35%와 대학별 값은 화면 구성을 위한 숫자다. 실제 원본 조회의 결과로 해석하지 않는다. 운영에서는 승인된 분포만 서버에서 조회한다.

1번 페이지와 2027 전형 정보는 v0.5를 유지한다. 회원의 개인 성적 이용권한과 2번 페이지에는 이번 v0.6을 우선한다.
