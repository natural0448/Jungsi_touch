# 개인 리포트와 회원 권한 v0.6

작성일: 2026-09-23 · 기획·검증용 예시 단계

## 확정 요구

- 1번 페이지: 기존 4개년 입시결과와 2027 전형 정보 조회를 유지한다.
- 2번 페이지: 본인의 실제 수능 성적에 대한 개인 리포트.
- 총성적: 국어 표준점수 + 수학 표준점수 + 탐구1 표준점수 + 탐구2 표준점수.
- 비교집단: 국어·수학·탐구 2과목 성적이 모두 있는 전체 응시자. 문·이과 구분을 두지 않는다.
- 일반가입자도 성적을 입력하고 위 총점의 통합 누적백분위까지 이용한다.
- 유료가입자는 관심 대학·모집단위 목록을 구성하고 대학별 분석을 포함한 리포트를 출력한다.
- 성적 판별 근거는 정시판 S파일, 고속성장, 서울중등진학을 다시 검토한다. 수시판 S-file의 내신·수시 결과는 정시 총점·누적 계산 근거에서 제외한다.

이 결정이 v0.4의 ‘일반가입자는 개인 성적 입력·분석 불가’를 대체한다. v0.5의 모집정보 정의와 v0.3의 3티어·팀 전체 접근 전제는 이어 적용한다.

## 회원 기능

| 기능 | 일반가입자 | 유료가입자 |
|---|---|---|
| 1번 페이지 공통 자료 조회 | 가능 | 가능 |
| 실제 수능 성적 등록·확인 | 가능 | 가능 |
| 국수탐2 총점·통합 누적 리포트 | 가능 | 가능 |
| 대학·모집단위별 개인 환산·분석 | 제공하지 않음 | 가능 |
| 관심 대학 리스트 구성·비교 | 제공하지 않음 | 가능 |
| 대학 분석을 포함한 전체 리포트 출력 | 제공하지 않음 | 가능 |

본인이 볼 수 있는 기본 화면의 브라우저 인쇄·캡처 자체를 기술적으로 막는 기능은 상품 권한에 포함하지 않는다. 유료 범위는 서버가 생성·제공하는 대학 분석과 전체 리포트다.

## 2번 페이지 흐름

1. 성적 등록: 직접 입력 또는 성적표 업로드 → 인식한 시험 학년도·과목·점수 확인 → 사용자 확정.
2. 리포트 상단: 시험 학년도, 입력 성적 요약, 총점과 ‘전체 응시자 기준 추정 상위 ○%’.
3. 바로 아래에 ‘국어·수학·탐구 2과목 유효 성적 보유자 기준’과 자료 기준일을 표시한다.
4. 유료 영역: 대학명·모집단위 검색 및 목록 추가 → 선택 대학별 결과 출력.
5. 인쇄/PDF: 성적 요약 → 통합 누적 → 선택 대학 목록과 분석 → 산출 기준. 출력 시점의 입력·모델·대학 규칙 버전을 고정한다.

입력 성적표의 영어·한국사 등급은 별도 표시한다. 총점에는 넣지 않으며 대학별 반영 단계에서 공식 규칙에 따라 사용한다. 사용자는 문·이과를 선택하지 않는다. 선택과목은 과목 유효성 확인과 대학별 반영 규칙에 필요하므로 보존한다.

업로드 형식·OCR 엔진·개인 성적 보관기간은 미정이다. OCR 결과를 검토하지 않은 채 확정 성적으로 저장하거나 자동 계산하지 않는다. 참고 S파일의 저장된 예시 성적을 사용자의 실제 성적으로 취급하지 않는다.

## 관심 대학 리포트 항목

- 대학·모집단위·전형·모집군.
- 해당 학년도 선발인원·추가 및 변경 인원·최종인원.
- 본인의 대학별 환산점수.
- 검증된 대학별 분포가 있을 때 대학별 환산점수의 누적 위치.
- 선택한 기준의 과거 입시결과. 합격권·상위 70%를 구분하고 당시 학년도·점수 기준을 유지한다.
- 성적 조건상 지원 가능 여부와 확인할 조건. 거주·학교 이수 등 미확인 자격은 별도 확인 필요로 표시한다.

통합 총점 누적 하나만으로 모든 대학의 개인 환산점수·유불리를 정하지 않는다. 같은 총점이라도 과목 구성에 따라 대학 환산이 달라진다. 대학별 누적의 비교집단을 통합 전체 집단으로 동일하게 만들 수 있는지는 별도 검증한다.

검증되지 않은 합격확률·안정/적정/소신 판정을 임의로 붙이지 않는다. 전년도 점수를 올해 점수로 재환산하려면 원 성적 조합 또는 검증된 변환 근거가 있어야 한다.

## API와 응답 범위

- POST /api/v1/overall-reports: 로그인한 일반·유료가입자. 성적 검증 후 통합 총점과 승인된 통합 누적을 반환.
- POST /api/v1/reports/{id}/university-results: 유효한 유료 권한과 본인 리포트 확인 후 선택 대학 분석.
- GET /api/v1/reports/{id}/print: 유료 권한·소유자 확인 후 전체 출력 리포트.
- 일반 응답에는 대학별 개인 계산 결과를 포함하지 않는다. 화면에서 가리는 방식으로 제한하지 않는다.
- 모든 누적 조회와 환산은 서버에서 수행한다. 전체 누적표·모델·원본 표본을 브라우저에 배포하지 않는다.
- 유료가 만료되어도 일반 통합 누적 기능은 유지한다. 과거 유료 리포트 재열람 정책은 별도 결정한다.
