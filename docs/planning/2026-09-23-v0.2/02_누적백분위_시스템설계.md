# 자체 누적백분위 시스템 설계 v0.2

작성일: 2026-09-23 · 상태: 구현을 위한 제안. 대상 학년도·대학·추정 알고리즘 확정 전.

## 1. 지표를 분리한다

| 지표 | 의미 | 계산에 필요한 정보 |
|---|---|---|
| 대학별 환산점수 | 대학의 해당 학년도 규칙으로 산출한 점수 | 개인 성적, 공식 반영 규칙·가산점·변환표·반올림 |
| 만점 대비 득점률 | 환산점수÷해당 만점 | 점수와 만점. 응시자 분포는 사용하지 않음 |
| 과목별 상위 누적비율 | 같은 과목 비교집단에서 해당 점수보다 높거나 같은 점수의 비율 | 공식 과목별 점수 인원, 동점 정책, 분모 |
| 합산/대학별 상위 누적비율 | 같은 비교집단에서 합산점수/대학 환산점수가 더 높거나 같은 비율 | 동일 응시자의 과목 조합을 표현하는 결합분포 |
| 합격 확률 | 정의한 전형 결과가 발생할 가능성 | 지원·등록 행동, 모집·충원 및 결과 데이터와 별도 예측·검증 |

사용자에게는 ‘우리 누적백분위’의 쉬운 표현으로 **‘추정 상위 ○%’**를 제안한다. 숫자가 작을수록 상위임을 표시한다. 과목별 공식 분포에서 직접 산출한 값과 합산 모델 추정치는 구분한다.

## 2. 상위 누적비율의 계산 계약

점수가 클수록 유리한 지표에서 비교집단 C의 각 성적 조합을 xᵢ, 가중치를 wᵢ, 대학·전형 규칙 버전 r의 계산 함수를 gᵣ이라고 한다. 사용자의 환산점수는 s이다.

- 엄격 상위 비율: U₍>₎(s) = 100 × Σᵢ∈C wᵢ·1[gᵣ(xᵢ)>s] ÷ Σᵢ∈C wᵢ
- 동점 포함 상위 비율: U₍≥₎(s) = 100 × Σᵢ∈C wᵢ·1[gᵣ(xᵢ)≥s] ÷ Σᵢ∈C wᵢ
- 동점 구간: [U₍>₎, U₍≥₎].
- 대표값이 필요하면 구간 중점 등을 별도 정책으로 선택한다. 기본 표시 정책은 아직 확정하지 않는다.

실제 전수 인원이면 wᵢ=1, 공식 점수 구간을 합산할 때는 인원수, 가상 응시집단이면 추정 가중치다. 가상 집단 행 수를 실제 응시자 수로 표시하지 않는다.

동점은 대학이 정한 최종 반올림·절사 단계 이후의 값으로 판정한다. 계산은 고정 소수점 또는 정확한 십진 규칙을 사용하고, 임의의 ±0.001을 모든 대학에 공통 적용하지 않는다.

### 저장·표시 규칙

- 내부 비율은 0~1로 통일하고 화면에서 ×100하여 %로 표시한다. 원본 단위도 보존한다. 서울중등진학 B열은 0~1, 고속성장·이투스 누적표는 % 수치이므로 수입 시 100배 오류를 막는다.
- 동점 구간은 같은 점수의 인원 범위다. 모델 가정에 따른 범위나 통계적 신뢰구간이 아니다.
- ‘최상위 0%’는 ‘해당 점수보다 높은 사람이 없음’과 ‘같은 점수도 없음’을 혼동하게 한다. 동점 포함 비율과 표현 정책을 함께 제공한다.
- 공개 분포의 반올림된 비율보다 원 인원 합계를 우선해 재계산한다.
- 기준표만 사용하는 보간은 정책을 버전으로 보관하고 단조성을 지킨다. 정확한 인원별 분포가 있으면 계단형 누적분포를 우선하며, 동점 질량을 선형 보간으로 지우지 않는다.
- 표 제공 구간 밖은 범위 밖 상태로 반환한다. 근거 없는 외삽과 작은 양수 상수로의 치환을 하지 않는다.

## 3. 공식 과목별 분포만으로 알 수 있는 것과 없는 것

공식 도수분포의 score→count를 높은 점수부터 합산하면 그 과목 전체 응시자의 상위 누적비율은 계산할 수 있다. 영어처럼 등급별 인원만 확보하면 등급 경계별 누적비율은 계산할 수 있지만 등급 안의 원점수 순서는 알 수 없다.

2026학년도 공식 자료에서 국어 490,989명, 수학 471,374명, 영어 487,941명으로 분모가 다르다. 과목별 누적비율의 분모를 임의로 전체 응시자 수나 경쟁사 표의 455,286명으로 바꾸지 않는다.

또한 국어 분포와 수학 분포만으로 두 점수를 같은 학생끼리 연결할 수 없다. 다음은 실제 수능이 아닌 수학적 예시다.

| 가상 집단 | 학생 4명의 (국어, 수학) 점수 조합 | 각 과목의 분포 | 합계 180점 이상 |
|---|---|---|---|
| A | (100,100) 두 명, (50,50) 두 명 | 100점 두 명, 50점 두 명 | 50% |
| B | (100,50) 두 명, (50,100) 두 명 | 100점 두 명, 50점 두 명 | 0% |

같은 과목별 인원 분포라도 합산 상위 비율이 달라진다. 이를 ‘결합분포가 식별되지 않는다’고 표현한다. 공개 자료가 틀렸거나 부족한 품질이라는 의미가 아니라 자료가 제공하는 정보 단위의 차이다.

### 필요한 추가 정보

| 추가 근거 | 해결하는 문제 | 확보 전 상태 |
|---|---|---|
| 영역 응시 조합별 인원 | 국수탐2 유효 응시집단·결시·미응시 처리와 분모 | 분모 미확인으로 표시 |
| 같은 응시자의 복수 과목 성적 표본 또는 공개 교차표 | 국어–수학–탐구·영어의 상관 및 조건부 분포 | 모델 가정에 의존 |
| 선택과목 조합과 점수대별 분포 | 탐구 혼합·수학 선택에 따른 차이 | 전체 집단 비율로 일괄 대체하지 않음 |
| 상위권의 과목 조합과 표본 구성 | 의약학 등 극상위 꼬리 구간 검증 | 정밀한 상위 지표 제공 조건 미충족 |
| 전년도 연계 성적·현재 시험과의 연결 근거 | 모형의 출발점과 연도별 보정 | 전년도 분포를 당해 연도 정답으로 사용하지 않음 |

연계 성적에는 이름·연락처가 필요 없다. 선택과목, 영역별 성적, 시험 연도, 수집 경로·표본 범위처럼 추정에 필요한 최소 항목만 설계한다. 이를 실제로 수집할지와 동의·보관 방식은 별도 결정 대상이다.

## 4. 구현할 통계 처리 흐름

### 단계 A — 공식 분포 정규화

원본별 학년도·시험·공표일·수정일·과목·점수 종류·인원을 적재한다. 표준점수별 도수, 등급별 도수, 선택과목별 응시 인원, 응시 조합 교차표를 각각 보존한다.

합계·중복·누락을 검증한 후 과목별 상위 누적비율을 생성한다. 공개되지 않은 조합은 unknown으로 남기며 0명으로 치환하지 않는다.

### 단계 B — 비교집단 정의

‘전체 수능 응시자’, ‘국수탐2 성적이 있는 응시자’, ‘과탐 2과목 응시자’, ‘특정 성적 조건을 충족한 집단’은 다른 모집단이다. 국수탐2의 정의, 직탐·탐구 1과목·혼합탐구·결시의 포함 여부와 N의 근거를 기록한다.

대학 지원 자격에는 거주·학교 이수 등 성적만으로 알 수 없는 항목도 있으므로 성적 조건 집단을 실제 지원 가능자 전체로 표시하지 않는다.

직접 비교 가능한 누적비율은 같은 학년도·같은 비교집단·같은 모델 버전에 한정한다. 대학에 따라 계산 가능한 과목 조합이 달라 분모가 달라지면 해당 집단 이름을 표시하고 자동 유불리 순위에서 분리한다.

### 단계 C — 과목 조합 모델

**현재 확보 계획처럼 과목별 분포만 있을 때:** 서로 다른 상관 가정에 따른 가상 집단을 만들어 합산·대학별 위치가 얼마나 달라지는지 연구한다. 이는 식별 한계를 측정하는 시나리오다. 과목 점수를 독립적으로 뽑은 결과를 검증된 단일 누적백분위로 공개하지 않는다.

**연계 표본이나 교차표를 확보한 뒤:** 그 자료를 과목 조합의 출발점으로 삼고, 공식 점수·등급 인원에 맞게 가중치를 보정하는 방법을 우선 검토한다. 표본에 없는 조합은 0%로 확정하지 않고 지원 범위·추가 모델 필요 상태를 기록한다.

레이킹/IPF는 알려진 주변 합계에 맞춰 표본 가중치를 조정하는 검토 후보다. 상관 구조 후보로 코퓰라를 검토할 수 있으나 상관행렬이나 이를 추정할 표본이 별도로 필요하다. 주변 합계가 맞았다는 사실만으로 대학별 분포가 검증되지는 않는다. [미국 Census의 가중치 보정 연구](https://www.census.gov/library/working-papers/2022/adrm/RRS2022-03.html), [statsmodels GaussianCopula 공식 문서](https://www.statsmodels.org/dev/generated/statsmodels.distributions.copula.api.GaussianCopula.html)

방법과 라이브러리는 확정 스택이 아니다. 선정 전 상위권 꼬리, 탐구 조합, 희소 구간, 가중치 집중, 실제 관측과의 차이를 비교한다.

### 단계 D — 대학별 재계산

동일한 성적 조합 xᵢ에 대학별 공식 반영 규칙 gᵣ을 적용한다. 표준점수·백분위·변환표준점수·영어/한국사 등급점수·가산점·탐구 1/2과목 선택·높은 영역 선택·반올림 순서를 그대로 반영한다.

국수탐 총점 한 축만으로 모든 대학 누적을 변환하지 않는다. 총점이 같은 두 학생도 국어·수학 비중과 선택과목 가산점 때문에 대학별 환산 결과가 달라질 수 있다.

### 단계 E — 분포 집계와 배포

환산점수별 가중 인원을 합산하고 엄격 상위·동점 포함 누적값을 생성한다. 규칙 버전+비교집단 버전+모델 버전+원자료 묶음을 배포 단위로 고정한다.

개인 성적 입력 시 매번 전국 가상 집단을 생성할 필요는 없다. 사전 생성한 대학별 점수–누적표에서 조회하고, 입력 성적의 대학 환산 계산은 같은 규칙 버전을 사용한다.

### 단계 F — 검증·변경 설명

공식 인원과의 일치 검증, 외부 연계 표본 검증, 전년도→다음 연도 평가, 상관 가정 민감도, 버전별 후보 순서 변경을 구분한다. 경쟁사 표는 동일 학년도·모집단·지표가 확인된 경우 보조 비교 자료로만 사용한다.

원자료가 같아도 규칙 변경으로 달라진 결과와 모델 변경으로 달라진 결과를 분리해서 설명한다.

## 5. 논리 데이터 계약 제안

실제 DB·언어는 미정이다. 다음은 테이블명과 필수 의미의 초안이다.

| 개체 | 주요 필드·키 | 필수 검증 |
|---|---|---|
| distribution_sources | source_id, 시험 학년도, 공표·확인일, 문서 버전, 원본 해시, source_locator | 공식·추정·예시 구분, 원본 보존 |
| subject_frequency_bins | source_id, subject_id, score_type, score/grade, count, missing_status | 같은 원본·과목·점수 중복 금지, 비음수 정수, 합계 대조 |
| population_definitions | population_version_id, 포함·제외 조건, 응시 조합, N, N_status, 근거 | 서로 다른 과목 분모 혼용 금지, 미확인 N≠0 |
| joint_model_versions | model_version_id, seed/source 목록, 교차표·상관 가정, fitting 방법, 재현 seed, 검증 보고서, 상태 | 관측·가정 구분, 표본 범위, 버전 불변 |
| weighted_score_profiles | model_version_id, profile_id, 과목·표준점수·백분위·등급·미응시 상태, weight | 성적 조합 유효성, 가중치 유한·비음수, 분모 일치 |
| score_rule_versions | rule_version_id, 적용 학년도·모집행, 공식 출처, 반영·반올림·변환표 버전 | 기존 모집행 키에 연결, 공식 규칙 검수 |
| score_distribution_bins | release_id, population_version_id, rule_version_id, score, weight_at_score, ratio_gt, ratio_ge | 비율 0~1, ratio_gt≤ratio_ge, 단조성, 동점 보존 |
| percentile_releases | release_id, sources, model_version_id, rule_versions, 공개 구간, 기준일, 검증 상태 | 이전 배포본 보존, 범위 밖 처리 |
| score_comparison_runs | run_id, 입력 버전, release_id, rule_version_id, 환산점수, 누적값·구간·상태 | 동일 입력·동일 버전 재현. 성적 보관 여부 미정 |

기존 모집행 데이터의 학교별 PK·연도 관계를 재사용한다. 모집행 데이터에 임의의 캠퍼스ID·계산식 컬럼을 추가하는 결정은 하지 않는다. 환산 규칙은 별도 엔진의 버전 개체로 설계한다.

API 응답은 score와 만점 외에도 다음 의미를 갖춰야 한다.

- 비교집단 이름·버전, 적용 학년도와 시험.
- ratio_gt / ratio_ge / 대표값 정책, 단위 fraction.
- observed_distribution / model_estimate / scenario_only 상태.
- 동점 구간과 모델 시나리오 범위를 별도 필드로 표시.
- source_release_id, rule_version_id, model_version_id, 근거 링크.
- model_unvalidated / missing_input / rule_unavailable / population_undefined / out_of_range / not_applicable 등 미산출 사유.

결측·미공개·해당 없음·실제 0을 분리한다. 미확인 상태를 0% 또는 빈 문자열로 감추지 않는다.

## 6. 검증 계획과 공개 조건

| 검증 대상 | 실제로 확인할 것 | 통과가 의미하지 않는 것 |
|---|---|---|
| 공식 도수 | 과목별 합계·누적합, 원본 대조 | 합산 결합분포의 정확성 |
| 모델 보정 | 공식 주변분포·확보된 교차표 오차 | 미관측 상관·꼬리 정확성 |
| 가상 집단 | 불가능 조합, 결시 처리, 가중치 집중, 반복 생성 재현 | 실제 학생 원자료 확보 |
| 대학 환산 | 공식 사례·경계값, 가산점, 선택영역, 반올림 | 합격 가능성 검증 |
| 누적 집계 | 가중치 합·동점·단조성·범위 밖·단위 변환 | 모델 가정이 맞다는 증명 |
| 외부 평가 | 별도 연계 표본/연도에서 점수대별 오차와 순서 | 다른 학년도·집단에도 동일 성능 보장 |
| 결과 설명 | 공식 점수·모델 누적·과거 컷의 구별 | 이용자가 합격을 보장받음 |

상위 꼬리는 전체 오차 평균만으로 승인하지 않는다. 해당 구간의 실제 표본·가중치 집중 및 유효 표본 크기를 함께 본다. 모델 가정 범위를 임의로 95% 신뢰구간이라 부르지 않는다.

현재 단계에서 수치 정확도 목표나 출시 허용 오차는 확정하지 않는다. 평가 자료를 확보한 뒤 사용자 판단에 영향을 주는 오차 수준을 기준으로 정한다.

## 7. 입시결과와 연결할 때의 제약

등록자 70% 컷과 전국 응시자 상위 누적비율은 분모가 다르다. 그 컷을 당시의 검증된 동일 점수 기준 분포에 위치시킬 수는 있지만, 이를 합격 확률로 바꾸지는 않는다.

전년도 환산 총점이나 평균 백분위만으로 올해 새 반영비율에 따른 점수를 정확히 복원할 수 없다. 원 성적 조합 또는 출처가 설명하는 변환 방법이 있어야 하며, 불가하면 원년도 값으로 표시한다. 이투스의 ‘2024→2025’ 열은 이 기능의 참고 사례이지만 우리 서비스의 공식 변환 정답을 제공하는 것은 아니다.
