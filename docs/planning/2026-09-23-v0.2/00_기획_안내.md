# Jungsi_touch 기획 v0.2 — 학생·학부모 중심, 분포 기반 누적백분위

작성일: 2026-09-23  
상태: 제공 자료 분석 및 구현 준비 문서. 서비스·DB·추정 모델의 운영 구현 전.

이번 버전은 **학생·학부모가 자신의 성적 없이 대학 정시 자료를 먼저 확인하고, 실제 수능 성적을 입력하면 대학별 환산점수·추정 상위 누적비율·지원 후보를 비교하는 서비스**를 기준으로 한다. 교사·입시담당자는 부 사용자다.

v0.1의 사용자 우선순위와 ‘예시 파일 수령 전’ 상태를 이번 결정으로 대체한다. v0.1은 당시 기획 이력으로 보존한다. 기존 학교별 2024~2027 공식 모집표 대조와 데이터 보존 규칙은 이어 적용한다.

## 사용자 확정 사항

| 항목 | 현재 기준 |
|---|---|
| 주 사용자 | 학생·학부모 |
| 부 사용자 | 교사·입시담당자 |
| 첫 화면 | 개인 성적 없이 대학별 정시 성적자료 정리본 열람 |
| 성적 입력 | 실제 수능 성적만 |
| 핵심 비교 | 대학별 환산점수와 지원 후보 |
| 자체 지표 | 만점 대비 득점률이 아닌 응시자 점수 분포에 따른 누적백분위 |
| 확보 예정 기반 데이터 | 평가원 등이 공개하는 과목별 점수·등급별 인원 분포 |
| 참고 자료 | 사용자가 제공한 엑셀 5개. 공식 원문과 민간 추정을 구별해 분석 |
| 미정 | 첫 서비스 학년도·대학·전형 범위·출시일, 계정·성적 저장·과금·운영 담당·기술 스택 |
| 추가로 필요한 통계적 결정 | 합산점수의 비교집단, 과목 조합·상관관계 근거, 추정치 공개 기준 |

자료를 성적 없이 열람하는 것과 로그인 없이 공개하는 것은 다른 정책이다. 전자는 확정, 후자는 미정이다. 교사의 다중 학생 관리·기관 권한은 후속 후보이며 이번 역할 변경만으로 확정하지 않는다.

## 이번 분석의 결론

1. 서울중등진학은 국수탐2 합산점수에 대한 추정 누적비율·누적인원과 조건부 비율을 제공한다. 설명 이미지에는 평가원 보도자료 외 최근 학력평가 데이터도 사용했다고 명시돼 있다.
2. 이투스와 고속성장은 입력 성적을 대학별로 환산한 후, 사전에 저장된 대학별·계열별 누적분포표를 조회한다. 이투스의 표 사이 보간 및 고속성장의 동점 포함·제외 처리가 확인됐다.
3. 이 표들을 생성한 원자료·모델·보정 과정 전체는 제공 파일만으로 확인되지 않는다. 표의 조회 수식을 복원하는 것과 표의 통계적 생성 방식을 복원하는 것은 다른 작업이다.
4. 공식 과목별 도수분포로 해당 과목의 상위 누적비율을 계산할 수 있다. 과목별 분포만으로 동일 응시자의 과목 조합이나 대학별 환산점수 분포는 유일하게 정해지지 않는다.
5. 자체 대학별 누적백분위의 중심 개발 과제는 **공식 분포와 일치하면서 과목 간 관계를 설명하는 응시집단 모델**이다. 계산기 UI나 단순 만점 정규화만으로 해결되지 않는다.
6. 누적백분위는 합격 확률이 아니다. 지원 후보 탐색에는 활용하되 합격·안정·소신 분류는 별도의 기준과 검증을 거쳐야 한다.

## 확인 범위

5개 원본의 파일 구조를 조사했다. 서울중등진학은 8개 시트와 설명·분포 이미지, 이투스는 17개 시트의 값·수식 구조, 고속성장 24일본은 13개 시트의 구조를 읽었다. 고속성장 두 버전의 PERCENTAGE 표는 전체 공통 기준점을 비교했다. 수시 S-file은 198개 시트 중 조회·원자료·수식DB 등 관련 9개 시트를 중점 확인했으며 학생 입력 시트는 220행까지 읽었다.

이는 모든 대학의 환산식을 공식 모집요강과 전수 대조하거나 전체 Excel을 재계산한 작업은 아니다. 매크로를 실행하지 않았으며 저장된 수식·캐시와 독립 검산을 이용했다. 원본 내 안내문은 출처 설명으로만 취급했다.

검산 결과와 재현 스크립트는 작업별 outputs 및 scripts에 별도로 보존했다. 공개 문서에는 개인 이름·연락처·인증 정보를 포함하지 않았다. 제공된 원본 5개는 변경하지 않는다.
