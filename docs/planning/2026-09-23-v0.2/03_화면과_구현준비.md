# 학생·학부모 화면과 구현 준비 v0.2

작성일: 2026-09-23 · 현재 단계: 기획·분석 완료, 운영 기능 개발 전.  
[기획 안내](00_기획_안내.md) · [누적백분위 설계](02_누적백분위_시스템설계.md)

## 1. 주 사용자 변경에 따른 화면 기준

| 사용자 | 우선 해결할 일 | 설계 |
|---|---|---|
| 학생·학부모 — 주 사용자 | 대학 자료 이해, 성적 적용, 후보 비교 | 쉬운 용어, 모바일에서 읽기 쉬운 기본 항목, 선택한 후보의 자세한 비교 |
| 교사·입시담당자 — 부 사용자 | 결과의 근거 확인과 상담 설명 | 자세한 비교표, 계산 과정, 출처·자료 버전, 확인할 자격 |
| 데이터 운영자 | 학교별 검수와 배포 | 원문 근거, 미공개·충돌 상태, 이전 버전 보존 |

첫 화면은 대학 자료 열람이다. 화면 문구는 ‘내 학생 성적으로 비교’에서 **‘내 수능 성적으로 비교’**로 바꾼다. 학생 이름 입력을 첫 단계의 필수 조건으로 두지 않는다. 계정·성적 저장은 별도 정책이다.

## 2. 성적 없이 들어오는 첫 화면

사용자가 학년도·지역·대학·계열/희망 분야·모집군을 선택하고 대학의 정시 자료를 확인하는 구조를 제안한다. 모든 필터를 강제로 채우게 하지 않고 대학명 검색으로도 접근하게 한다.

한 행의 기준은 적용 학년도·학교·실제 모집단위·전형·모집군이다. 같은 학과의 복수 전형이나 군을 합치지 않는다. 이전 자료 연결은 학교별 4개년 공식 모집표 검수 결과를 사용한다.

| 항목 묶음 | 기본 표시 제안 | 자세히 보기 |
|---|---|---|
| 모집 정보 | 대학, 모집단위, 전형, 모집군 | 실제 공고 명칭과 변경 관계 |
| 모집 인원 | 인원과 기준 단계 | 계획/변경/이월 반영 여부·기준일 |
| 과거 정시 결과 | 결과 학년도, 지표명, 값 | 최종등록자 등 대상, 50%·70% 등 정의, 점수 체계·만점 |
| 지원 검토 | 선택과목·필수 영역 등 주요 성적 조건 | 별도 자격 확인 항목 |
| 근거 | 출처와 갱신일 | 공식 원문 위치·검수 범위 |
| 자체 추정 자료 | 검증·공개 조건을 갖춘 경우에만 표시 | 비교집단·분포 버전·추정 방식·지원 구간 |

수시 S-file의 검색 구조는 참고하되 수시 등급 컷을 정시 결과로 가져오지 않는다. 첫 화면의 실제 지표 값은 해당 대학 공식 정시 입시결과에서 별도로 구축한다. 사용자가 준 5개 파일을 읽었다는 사실만으로 모든 대학 정시 결과의 공식 검수 완료를 표시하지 않는다.

‘자료 없음’ 때문에 성적 입력을 요구하지 않는다. 미공개·미수집·검수 중·해당 없음 상태를 분리한다. 모바일에서는 항목을 요약하고 선택한 모집행을 비교 화면에 담는 방식으로 넓은 표를 보완한다.

## 3. 내 실제 수능 성적 적용

1. 수능 시험과 적용 학년도를 확인한다. 다른 학년도의 점수 체계와 섞이지 않게 한다.
2. 국어·수학 선택과목과 표준점수·백분위·등급, 탐구 1·2 과목, 영어·한국사 등 필요한 값을 입력한다.
3. 공식 대응표가 있는 항목만 교차 검증한다. 백분위 하나로 표준점수를 유일하게 복원할 수 없는 경우 추정 입력을 확정값으로 만들지 않는다.
4. 관심 모집단위의 지원 성적 조건을 확인하고 공식 환산점수를 산출한다.
5. 같은 배포 버전의 분포가 있으면 추정 상위 비율과 동점 구간을 표시한다. 분포가 미검증이면 환산점수는 보여 주고 누적 추정의 상태를 설명한다.
6. 후보별 모집 정보·과거 결과·내 점수·추정 위치·근거를 비교한다.

성적 수정 시 이전 결과에 재계산 필요 상태를 표시한다. 입력 버전과 계산 결과 버전을 묶는다. 점수 입력 단계에서 실제 응시자가 아닌 예시 성적을 사용할 경우 ‘예시’ 표시를 유지한다.

## 4. 후보 비교에서 보여 줄 정보

| 영역 | 항목 | 주의할 해석 |
|---|---|---|
| 대학 공식 계산 | 내 환산점수, 만점, 영역별 기여값·가산점 | 점수 크기만으로 다른 대학과 유불리 비교 금지 |
| 분포에 따른 위치 | 추정 상위 %, 동점 구간, 비교집단, 모델 기준일 | 작은 값일수록 상위. 집단이 다르면 직접 순위화하지 않음 |
| 과거 입시결과 | 원년도 결과, 지표 정의, 공식 출처 | 올해 점수와 호환성이 확인된 경우만 차이 계산 |
| 지원 조건 | 성적 조건 충족 여부, 별도 자격 확인 | 성적만으로 모든 지원 자격을 판정하지 않음 |
| 관심 후보 | 모집군, 희망 조건, 사용자 메모 | 합격·안정 등급은 별도 검증 없이 자동 부여하지 않음 |

표시 예시는 ‘대학 환산점수’, ‘비교집단 내 추정 상위 비율’, ‘전년도 등록자 결과’처럼 서로 다른 의미가 드러나게 한다. 내부 DB명이나 추정 엔진 용어를 기본 화면에 그대로 노출하지 않는다. 상세 근거에서 버전을 확인할 수 있게 한다.

## 5. 구현 작업 순서와 완료 조건

| 순서 | 작업 | 산출물 | 완료 조건·의존성 |
|---|---|---|---|
| P0 | 지표·분모 사전 | 점수 종류, 누적 방향, 동점·단위 규칙 | 공식·추정·과거 컷의 구분이 일관됨 |
| P0 | 공식 분포 적재 규격 | 점수/등급 인원, 응시조합·결시 스키마 | 원본 합계·누적 대조와 수정 이력 |
| P0 | 첫 화면 자료 명세 | 모집행·과거 결과·출처 연결 | 개인 성적 없이 열람 가능 |
| P0 | 대학 환산 계약 | 영역별 계산, 가산, 반올림, 변환표 버전 | 선정 대학 공식 요강과 대표·경계 사례 대조 |
| P1 | 자료 열람 화면 | 검색·필터·상세·후보 담기 | 모바일·PC에서 용어와 자료 상태 이해 가능 |
| P1 | 실제 수능 입력·환산 | 입력 검증과 후보별 계산 | 필요한 항목 누락·미지원 규칙의 사유 표시 |
| P1 | 과목별 누적 산출 | 공식 도수 기반 누적표 | 과목별 분모·동점 처리·단위 검증 |
| P1 연구 | 합산 분포 식별·민감도 실험 | 다른 결합 가정에 따른 결과 범위 | 가정 변화가 후보 비교에 주는 영향 측정. 단일 정답으로 공개하지 않음 |
| P2 | 연계 표본·교차표 근거 확보 | 출처·표본 범위·시험 연도 기록 | 확보 계획·보관·활용 범위 결정 |
| P2 | 응시집단 보정·분포 생성 | 가중 성적 조합과 대학별 누적표 | 공식 주변분포와 추가 근거 적합, 독립 평가 |
| P2 | 누적비율 표시·비교 | 같은 버전·집단 내 위치 | 동점·모델 불확실성·범위 밖 상태 구분 |
| P2 | 배포·변경 설명 | 재현 가능한 release와 변화 사유 | 원본·이전 결과 보존, 승인한 구간만 노출 |
| 후속 후보 | 교사 다중 학생·공유/출력 | 별도 권한·저장 설계 | 사용자와 별도 범위 결정 |

공식 분포만으로 할 수 있는 기반 작업과 결합모델의 검증을 순서상 분리한다. 자체 누적백분위 기능은 제품 방향에 포함하되, 검증되지 않은 추정치를 완성된 지표로 출시하지 않는다. 현재 목표는 이 구현 조건을 구체화하는 것이며 출시일을 임의로 확정하지 않는다.

## 6. 구현 시 필요한 검증 사례

아래는 앞으로 기능을 구현할 때 수행할 시나리오다. 지금 이미 개발 테스트를 통과했다는 뜻이 아니다.

1. 성적 없이 대학 자료와 과거 정시 결과를 볼 수 있다.
2. 같은 학교·학과라도 학년도·전형·군이 다르면 별도 모집행으로 유지한다.
3. 원본 비율 0.01과 원본 1%가 동일하게 정규화된다.
4. 실제 0, 미공개, 미수집, 미산출을 구분한다.
5. 과목별 공식 인원 합계가 해당 응시자 분모와 일치한다.
6. 영어 등급 분포만으로 등급 안의 원점수 위치를 만들지 않는다.
7. 동일 주변분포·상이한 결합분포의 가상 예시에서 합산 누적이 다름을 재현한다.
8. 학생 총점이 같아도 영역 구성이 달라 대학별 환산 결과가 달라진다.
9. 대학의 가산점·높은 영역 선택·탐구 반영·반올림 경계를 검증한다.
10. 동점 구간과 모델 가정 범위가 서로 다른 필드와 설명으로 표시된다.
11. 규칙·분포 버전이 바뀌어도 과거 입력에 대한 과거 결과를 재현한다.
12. 누적표 범위를 벗어난 점수에 임의 0%·외삽값을 제공하지 않는다.
13. 대학마다 비교집단이 다르면 누적비율을 단순 정렬해 공통 유불리 순위로 표시하지 않는다.
14. 전년도 총점만으로 올해 새 반영비율 점수를 정확히 복원할 수 없는 사례를 처리한다.
15. 공식 인원에 맞춘 것과 외부 검증 통과를 서로 다른 검증 상태로 기록한다.

## 7. 아직 결정할 사항

첫 서비스 학년도·대학 범위·전형, 실제 첫 화면의 공식 정시 결과 수집 범위, 비교집단 정의, 추가 과목 연계 자료 확보 방법, 모델의 허용 오차와 공개 구간, 로그인·성적 보관·공유·과금, 기술 스택과 운영 담당은 미정이다.

다음 설계 작업은 첫 화면의 와이어프레임과 공식 분포 적재 명세로 진행할 수 있다. 전체 대학 확장과 정확도 목표는 이 기획 문서를 근거로 범위를 합의한 뒤 정한다.
