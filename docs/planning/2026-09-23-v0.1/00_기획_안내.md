# Jungsi_touch 시스템 기획 v0.1

작성일: 2026-09-23 · 상태: 예시 파일 검토 전 기획 초안 · 실제 구현 및 서비스 공개 전

**교사·입시상담자가 먼저 대학의 정시 성적자료 정리본을 열람하고, 실제 수능 성적을 입력하면 대학별 환산점수와 지원 후보를 비교하는 상담 서비스**로 기획한다.

이번 대화에서 확정한 방향은 반영했다. 예시 파일에서 구체화할 화면·지표, 첫 적용 학년도·대학 범위, 기술·운영 선택은 미정으로 남긴다.

## 확정된 두 사용 흐름

| 흐름 | 사용자가 하는 일 | 핵심 요구 |
|---|---|---|
| 첫 화면: 자료 열람 | 대학의 정시 성적자료 정리본을 검색·확인 | 개인 성적을 입력하지 않아도 사용 가능 |
| 상담: 성적 적용 | 실제 수능 성적을 입력하고 대학별 환산·후보 비교 | 대학별 계산 근거와 미산출 사유 확인 |

개인 성적 입력 없이 열람할 수 있다는 요구는 확정이다. 로그인 없이 누구나 공개 열람하도록 할지는 별도 정책이며 아직 확정하지 않았다. ‘정시 성적자료’의 구체 지표·점수 기준·대상 집단은 제공 예정인 예시 파일을 확인해 정의한다.

첫 화면에서 자료를 보고 ‘내 학생 성적으로 비교’를 선택하면 상담 흐름으로 이어지는 구성을 제안한다. 버튼 이름과 화면 배치는 예시 파일을 보고 다듬는다.

## 바로 이어서 할 작업

예시 파일을 받으면 표·시트·컬럼·주석·수식을 확인하고 다음 네 가지를 작성한다.

1. 첫 화면에 보여 줄 항목과 배치, 필터, 상세 보기.
2. 성적자료의 지표·단위·학년도·모집행 키를 설명하는 데이터 사전.
3. 실제 수능 한 사례의 입력→환산→지원 후보 비교 흐름.
4. 기존 모집행·연도 관계 데이터와 예시 자료의 연결, 추가 수집·검수 목록.

이 과정에서는 예시의 형식과 숫자의 공식 근거를 구분한다. 예시 자료가 화면의 기준인지 운영에 사용할 실제 데이터인지도 역할별로 기록한다.

## 이번 준비 작업의 범위

기존 문서와 데이터 구조를 읽고, 새 기획 문서 5개를 작성했다. 현재 확인한 자산은 모집요강·모집행·연도 관계 중심이며, 첫 화면에 사용할 정시 성적자료의 지표와 값은 예시 파일을 확인해야 한다.

이번에는 원본 데이터 수정·삭제, 신규 모집행 반영, DB 생성, 앱 설치, 서비스 배포를 수행하지 않았다. 기능 구현의 실제 검증은 해당 개발 단계에서 수행한다.
