# 3페이지의 중심은 사용자가 원하는 대학·학과의 직접 검색

2026-09-30 사용자 요구 보완. 3페이지는 1페이지처럼 대학명·학과명을 직접 입력해 보고 싶은 모집단위를 확인하는 화면이다. 추천 결과나 성적에 맞춘 후보 목록이 검색의 출발점이 되지 않는다. 4페이지는 유리한 대학 찾기 역할을 유지한다.

## 화면 흐름

1. 대학명만 입력하면 해당 대학의 서비스 대상 학과·모집단위를 조회한다.
2. 학과명만 입력하면 해당 학과명이 있는 여러 대학의 모집단위를 조회한다.
3. 대학명과 학과명을 함께 입력하면 같은 실제 모집행에서 두 조건을 모두 만족하는 결과를 조회한다.
4. 검색 결과에서 학과·전형·모집군을 선택하면 기본 상세를 연다. 추천 단계와 관계없이 상세 버튼을 사용할 수 있다.
5. 기본 상세에는 모집정보와 입결을 표시하고, 권한과 성적이 있으면 그 모집단위의 개인별 분석을 함께 표시한다.

지역·모집군은 사용자가 선택하는 보조 검색 조건이다. 도전·핵심·여유·추천 범위 밖 같은 개인 판정은 3페이지 검색 조건에서 제외했다. 학과별 추천 단계 요약 카드도 4페이지의 추천 탐색에 둔다. 3페이지는 학교명·학과명과 모집행이 먼저 보이는 검색 결과 표로 구성했다.

## 검색 결과에서 없어지면 안 되는 경우

- 추천 목록에 포함되지 않은 학교·학과
- 현재 성적으로 추천 범위 밖인 학교·학과
- 해당 학생의 지원 조건이 충족되지 않는 전형
- 성적을 아직 입력하지 않은 상태
- 환산식·누적·입결·예측 자료가 아직 확인되지 않은 모집단위

해당 항목은 검색 결과와 기본 상세를 유지하고, 개인 분석 영역에서만 부족한 자료 또는 확인된 상태를 설명한다. 지원 조건 미충족을 ‘자료 미확인’과 구분하고, 검색 결과가 없다는 사실을 합격 불가로 표현하지 않는다. 실제 자료에 없는 학교·모집단위를 지어내지 않는다. ‘전체’는 기존 서비스 대상 범위이며 실기 반영 전형 제외 원칙을 유지한다.

## 기본 조회와 개인별 분석

기본 검색·모집정보·입결 조회는 1페이지의 기본조회 정책에 맞추고, 내 환산점수·누적·지원 검토 결과와 핵심 지원 학교 기능은 기존 개인 분석 유료 정책을 적용하는 구현안이다. 비회원 접근 정책은 이번에 새로 확정하지 않는다.

성적 미입력과 일반가입자 상태에서도 원하는 모집단위를 검색하고 기본 상세를 확인할 수 있다. 개인 분석을 제공할 조건이 안 되면 그 영역에 성적 입력 또는 유료 분석 안내를 표시한다. 기존에 합의한 전체 누적과 4페이지 추천 정책은 유지한다.

## 서버와 데이터 구현 원칙

검색 API는 대학·모집단위 카탈로그를 기준으로 동작한다. 성적 리포트나 추천 결과 ID 목록이 없어도 기본 검색이 가능해야 한다. 기본 API는 검색 조건과 서비스 범위만 적용하고, 개인 성적·예측 분류는 반환하지 않는다.

개인 분석 API는 유료 권한·리포트 소유자·성적을 확인한 뒤 사용자가 요청한 실제 모집행 ID를 분석한다. 추천 밖의 모집단위도 요청할 수 있다. 카탈로그에 개인 결과를 결합할 때는 선택적으로 덧붙이며, 분석 결과가 없다는 이유로 모집행을 제거하는 내부 조인을 사용하지 않는다. 미계산·오류·규칙 미확인 등의 상태만 반환한다.

학교·캠퍼스·모집단위·전형·모집군·학년도 키와 출처·자료 기준일은 기존 검수 자료를 재사용한다. 원문 모집표 검수 또는 실제 전국 데이터 수집을 이번 화면 작업으로 완료 처리하지 않는다.
