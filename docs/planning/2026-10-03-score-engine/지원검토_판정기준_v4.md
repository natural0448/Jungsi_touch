# 지원 검토 구간과 예상컷 판정 기준

이 문서는 3페이지의 대학·학과별 개인 분석과 4페이지의 유리한 대학 추천에 적용할 지원 판정 방식을 정리한다. 사용자가 확정한 요구와 제안·미정 사항을 구분한다. 실제 판정 모델이나 운영 임계값을 완성했다는 의미는 아니다.

## 사용자 확정 사항

2026년 10월 3일 사용자는 지원가능성의 제공 수준으로 “지원 검토 구간과 예상컷, 판단 근거를 중심으로 제공”을 선택했다.

- 지원 검토 구간, 올해 예상 기준, 판단 근거를 중심으로 제공한다.
- 이번 확정 범위에는 수치로 된 합격확률 제공을 포함하지 않는다. 기존 계산 계약의 합격확률 null 상태와 맞는다.
- 모집단위·전형·모집군별로 판정한다. 대학 전체의 분류를 모든 학과에 복사하지 않는다.
- 환산 유불리와 학과별 지원 검토 구간은 별도 결과로 유지한다. 유리한 반영식이라고 모든 학과를 긍정 추천하지 않는다.
- 1페이지는 공식 입결 검색, 2페이지는 개인 성적 리포트, 3페이지는 원하는 대학·학과의 개인 분석, 4페이지는 유리한 대학 추천이라는 기존 구성을 유지한다.
- 개인 대학 후보·유불리·지원 검토는 기존 유료 범위다. 무료 사용자의 공식 입결 검색과 전체 총점 누적백분위 범위를 변경하지 않는다.

## 사용자 확정 예상컷 구성

공식 70%컷은 최종 등록자 중 해당 지표의 70% 위치 성적이다. 최저 합격점이나 전체 응시자 상위 70%가 아니다. 공식 지표의 정의와 대학 주석이 우선한다. 합격권이라는 참고자료의 지표도 출처별 정의를 보존한다.

다음 세 가지를 구분해야 한다.

1. 과거 공식 입결: 해당 연도의 실제 발표 지표와 값.
2. 올해 예상 70% 기준선: 동일한 공식 지표의 올해 값을 예측한 것.
3. 지원 판단용 예상 합격권: 지원 검토에 쓰기 위해 별도 모형과 상담 근거로 추정한 기준 또는 범위. 실제 최저 합격점으로 확정하지 않는다.

2026년 10월 3일 사용자는 “올해 예상 70% 기준선과 지원 판단용 예상 합격권을 구분해 제공”을 선택했다. 두 예측값을 각각 관리하고 표시하는 것은 확정 요구다. 기본 구간 자동 계산과 대학·학과별 직접 조정이라는 운영 방식도 확정했다. 도전·핵심·여유의 수치 경계와 계산 방법은 아직 미정이다. 예상 합격권을 판정 기준으로 쓰고 예상 70% 기준선을 비교 근거로 함께 보여주는 연결 방식을 제안한다.

공식 70%컷에 일정 점수를 빼는 규칙만으로 예상 최저 합격점을 만들지 않는다. 예상 합격권의 검증에 필요한 자료와 상담 근거는 별도 점검한다. 어느 한 예측값의 근거가 부족할 때 다른 지표를 이름만 바꿔 대신 제공하지 않는다.

두 예측값 각각에 적용 모집행, 시험·학년도, 예측 지표의 정의, 점수 척도·규칙 버전, 기본값·채택값, 근거·기준일, 자료 상태와 모델 버전을 기록하는 설계를 제안한다. 예상 합격권이 범위로 표현될 경우 구간의 의미와 경계값 포함 여부도 명시해야 한다. 자료가 부족하면 확인 가능한 과거 입결과 학생 환산점수를 표시하고, 미확정 예측·지원 판정은 확인 필요 상태로 둔다.

과거 두 입결 기준을 구분해 표시한다는 기존 요구를 이 질문으로 변경하지 않는다. 올해 예측 대상과 지원 판정 기준만 논의한다.

## 사용자 확정 판정 운영 방식

2026년 10월 3일 사용자는 “모델이 기본 구간을 계산하고, 필요한 대학·학과는 직접 조정”을 선택했다. 모든 대학·학과의 경계를 상담자가 먼저 수동 입력하는 운영을 기본으로 하지 않는다. 아래 계산 순서와 저장 구조는 이 결정을 구현하기 위한 설계 제안이다.

### 계산 순서 제안

1. 학생 성적과 해당 연도·모집행의 검증된 대학 반영식으로 개인 환산점수를 계산한다.
2. 해당 모집행에 연결된 올해 예상 70% 기준선, 지원 판단용 예상 합격권, 판정 정책을 조회한다.
3. 적용 범위와 버전이 맞는 상담 조정이 있으면 이를 반영해 채택 기준을 구성한다.
4. 채택 기준과 학생 환산점수를 비교해 도전·핵심·여유 또는 보류 상태를 산출한다. 환산 유불리는 별도로 계산한다.
5. 3페이지의 검색 결과와 4페이지의 추천 화면에 같은 결과와 근거를 전달한다.

예측값이나 실행 반영식이 검증되지 않았을 때 모델이 자동으로 운영 판정을 확정하는 기능은 아니다. 기본 계산과 조정 어느 쪽에도 충분한 근거가 없으면 확인 필요로 둔다. 1차 대학 탐색 모듈의 분류를 학과별 최종 판정으로 대체하지 않는다.

### 기본값과 조정값의 보존 제안

| 보존 항목 | 용도 |
| --- | --- |
| 기본 계산값 | 모델이 최초 산출한 지표·기준·판정 |
| 조정 내용 | 조정 대상, 방향 또는 값, 단위, 상담 판단과 근거 |
| 최종 적용값 | 해당 결과에 실제 사용한 기준과 판정 |
| 적용 범위 | 학년도·시험, 대학·캠퍼스, 해당 모집행 또는 명시한 모집행 목록 |
| 이력 | 모델·규칙·정책 버전, 조정자, 조정 시각, 적용 기준일 |

단일 값만 저장해 모델 계산과 상담 판단이 섞이지 않게 한다. 조정이 없으면 조정값은 null이며 기본값을 사용한다. 점수, 누적백분위, 구간 경계를 같은 단위로 취급하지 않는다.

대학 전체에 관한 이슈도 실제 적용 모집행을 확인한다. 다른 학과·전형·군에 무조건 복사하지 않는다. 공식 반영식이나 과거 입결 원문값의 수정과 올해 예측·판정의 상담 조정은 다른 이력으로 관리한다.

직접 조정할 항목의 상세 범위, 입력 화면의 상세 방식, 조정 폭의 산정, 이미 저장된 리포트의 갱신 방식은 후속 논의 항목이다. 사용자 제공 이슈를 기록하고 공식 발표를 확인하는 첫 사례는 마련했다. 이번 선택만으로 해당 항목이나 운영 숫자를 확정하지 않는다.

### 실제 상담 사례로 구체화할 내용

사용자는 등록금 무료화에 따른 국립대 전반의 올해 입결 상승 전망을 반영하도록 요청했다. 공식 발표를 확인한 2027년 지방국립대 신입생 등록금 지원 예산안과 사용자 전망을 구분한 첫 예측 이슈로 등록했다.

[국립대 등록금 지원 이슈 반영](국립대_등록금지원_이슈반영_v1.md)에 정책 출처, 확인한 적용 범위, 상승 방향, 모델 연결 방법과 미정인 상승 폭을 정리했다. 정확한 대상 모집행과 상승 폭은 아직 확정하지 않았다. 다른 대학·학과 사례에도 같은 사실·가설·조정·검증 구분을 적용한다.

## 판정 구간 설계 제안

다음은 구현 방향 제안이며 운영 경계값이 아니다. 예상 기준의 의미를 확정하고 비교 가능한 자료를 확보한 뒤 구체화한다.

| 구간 또는 상태 | 설계 방향 |
| --- | --- |
| 도전 | 채택한 지원 기준보다 성적이 부족한 쪽이지만, 검토 대상으로 둘 범위에 해당 |
| 핵심 | 채택한 지원 기준 주변의 검토 범위에 해당 |
| 여유 | 채택한 지원 기준보다 높은 성적이고, 설정한 여유 폭을 충족 |
| 검토 범위 밖 | 승인한 후보 탐색 범위 밖. 자료 부족과 구별 |
| 확인 필요 | 반영식, 비교 척도, 예상 기준, 지원요건 등의 필수 정보가 불확실 |
| 지원요건 미충족 | 공식 지원요건에 맞지 않는 것으로 확인됨. 긍정 추천에서 제외 |

수치 경계, 경계값 포함 방향, 동점 처리, 자료 부족 시 상태, 추가 전형이 있는 모집행의 표시 방식은 미정이다. 정해지기 전 예시나 화면 색상에서 임계값을 역산하지 않는다.

대학별 환산점수의 단순 크기로 대학을 정렬하지 않는다. 같은 대학·모집행의 비교에서는 점수 범위와 가산점·반영식·연도 대응을 맞춘다. 대학 간 누적 위치로 유불리를 비교할 때는 모집단과 척도의 차이를 확인한다.

## 올해 이슈 반영 제안

기본 예측, 올해 이슈 및 근거, 상담 조정, 채택한 기준을 각각 기록하는 운영을 제안한다. 대학·학과별 조정 방식과 수치 경계는 아직 확정하지 않았다. 공식 입결값과 대학 공식 환산식은 예측 조정과 별도로 관리한다.

개편으로 연도 비교가 안 되는 입결, 미공개 값, 수능 외 학생부·면접 등이 합쳐진 점수는 수능 부분점수와 자동 비교하지 않는다. 3개년 변동만으로 오차 범위를 통계적 신뢰구간이라고 표시하지 않는다. 동점·발표 반올림 범위와 모델의 추정 오차도 구분한다.

## 3페이지와 4페이지에 전달할 정보 제안

각 결과는 실제 모집행 식별자와 함께 다음을 전달하도록 설계한다.

- 내 대학별 환산점수와 적용 규칙 버전.
- 비교 가능한 과거 공식 입결과 지표 정의.
- 올해 예측 지표, 기본 예측 및 채택 기준, 산출 기준일.
- 지원 검토 구간 또는 보류 상태, 판정 정책 버전.
- 환산 유불리와 그 비교 기준.
- 판정 근거, 올해 이슈 반영 여부, 확인할 지원 조건.

수치 예측이 검증되지 않았으면 값과 이유를 보류한다. 가상 예시나 초안 결과를 운영용 판정으로 표시하지 않는다. 3페이지의 검색은 추천 목록에 없는 대학·학과도 조회할 수 있어야 한다. 4페이지는 같은 판정 결과를 대학별로 묶어 보여주고, 선택한 핵심 지원 학교 목록은 탐색 분류와 구분한다.
