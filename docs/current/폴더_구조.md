# 프로젝트 폴더 구조와 작업 위치

이 문서는 공통 명세 service_spec.json에서 생성한다. 현재 버전은 1.9.149이며 기획·라우팅·계층 문서를 같은 변경으로 갱신한다.

현재 dev 작업 기준은 Git 브랜치 develop이다. 구조 확인일: 2026-10-04 (Asia/Seoul). 조사 출발 커밋: d666a5f2bdbc846c65b5503de35c17d6d90088db.

origin/develop의 커밋된 폴더·파일 구조와 로컬 작업 공간의 주요 폴더 존재 여부를 기준으로 작성했다. 실제 원자료나 성적 내용은 구조 확인에 사용하지 않았다. 새 체크아웃에는 비공개 로컬 자료가 포함되지 않을 수 있다.

애플리케이션은 자신이 정의한 포트와 기존 계산 엔진을 사용한다. 인프라가 포트를 구현하며 프레젠테이션은 우리 서버의 허용 API 응답만 표시한다. data/는 비공개 실제 자료 위치이고 database/는 공유 가능한 DB 정의 위치다. FastAPI HTTP 진입점은 infrastructure/의 조립 어댑터다.

## 로컬과 외부의 비공개 영역

| 위치 | 확인/공유 상태 | 역할 |
| --- | --- | --- |
| Resource/ | 로컬에서 확인; Git 제외 | 공식 원문과 기존 자료 보관. Mojip-yogang/은 모집요강, Ip-gyeol/은 입결 자료 위치. 원문·이전 버전 보존. |
| data/ | 로컬에서 확인; Git 제외 | 정본·정제 자료·발행 명부·실제 성적/모형 등 비공개 데이터. 애플리케이션이 정의한 포트를 통해 공급. |
| datas/ | 현재 루트 목록에 없음; 사용하면 Git 제외 | 비공개 데이터 보관에 사용 가능한 제외 폴더. 문서 작성을 위해 새로 만들지 않았다. |
| outputs/ | 로컬에서 확인; Git 제외 | 산출물·검수 보고서·백업·보존한 런타임·문서 생성 및 Git 스냅샷 검산 결과. |
| docs/implementation/ | 로컬에서 확인; Git 제외 | 실제 원자료 값에 의존하는 분석·구현 검토 기록. 공유 코드와 현재 기획에 실제 값을 복사하지 않는다. |
| docs/team_sessions/ | 로컬에서 확인; 현재 develop에는 미추적 | 팀 세션 운영 자료. 공유 여부를 검토하기 전 현재 기획 정본으로 사용하지 않는다. |
| .env 계열, DATA_ACTIVE*.json | Git 제외; 위치·존재 여부는 운영 설정에 따라 다름 | 접속·인증 설정과 내부 정본 등록부. .env 예시 파일도 Git 제외. |
| .git/ | 로컬 Git 메타데이터 | 커밋·참조·체크아웃 관리. 다른 작업자의 상태와 잠금 파일을 임의로 정리하지 않는다. |
| 런타임·캐시·빌드 결과 폴더 | 생성되면 Git 제외 | node_modules, .venv, __pycache__, dist 등은 원본과 함께 보존한다. |
| 외부 Supabase·Google Drive | 비공개 외부 저장소 | 운영 DB와 고정 입출력 폴더의 실제 자료. 실제 연결 설정과 검수 상태는 백엔드 운영 준비에서 확인. |

이 표는 자료 보관 위치와 제외 규칙을 설명한다. 원자료 파일명·학생 정보·발행 명부 내용·폴더 ID·접속값은 문서에 넣지 않는다. scripts/와 tests/는 공유 파일과 로컬 전용 파일이 함께 있을 수 있다. 공유 가능한 파일 여부는 루트 .gitignore와 Git 추적 목록으로 확인한다.
