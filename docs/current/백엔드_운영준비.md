런타임 CPython 3.12 x64 Windows/Linux; 잠금 backend-runtime.lock.json.

```text
python -B scripts/bootstrap_backend_runtime.py --destination outputs/backend_runtime_NEW
python -B -m uvicorn jungsi_touch.infrastructure.http_api:configured_app --factory --host 127.0.0.1 --port 8000 --no-access-log
python -B scripts/probe_backend_connection.py
python -B scripts/run_committed_tests.py --staged
```

PYTHONPATH=새 runtime의 site + src; PYTHONDONTWRITEBYTECODE=1. 기존 runtime 폴더와 다운로드는 보존한다. SHA256 고정 공식 PyPI wheel을 새 목적지로 추출한다. 재실행에는 새로운 폴더를 지정한다. CI도 동일 lock을 사용한다. checkout/setup-python 액션 없이 ubuntu-24.04의 Git/Python3.12로 run_id/run_attempt별 새 경로를 만든다. 기존 경로는 중단하고 지정 github.sha 최초 checkout만 수행한다. fetch 전용 인증 환경, gc/maintenance 해제, 정리 명령 없는 runtime/검산 보존은 workflow.CI_snapshot_policy를 따른다.

## DB·헬스·실제 연결 확인

database/migrations/001_pre_data_platform.sql은 추가 정의만 제공한다. 자동 적용하지 않으며 기존 DB를 reset/drop/delete하지 않는다. 전용 jungsi_backend 스키마의 사용자/이용권/리포트 접근은 서버 역할과 SQL owner 조건으로 제한하고 anon/authenticated 직접 접근은 허용하지 않는다. schema_versions와 실제 11개 timestamptz/date 컬럼 형식을 함께 확인한다.

/health/live는 프로세스 UTC 시각만 확인한다. /health/ready는 설정 존재와 읽기 전용 DB 스키마·컬럼·UTC 세션·합성 SQL literal 왕복을 검사한다. ready가 인증 사용자/입시 자료/모형 검증 완료를 뜻하지 않는다. auth와 live_data 상태를 별도로 반환한다.

읽기 전용 probe는 실제 설정이 있을 때 DB default/effective timezone·스키마/컬럼 형식과 가상 SQL literal instant/date 왕복만 검사한다. 실제 사용자 표 조회·수정·마이그레이션 적용은 하지 않는다. Auth는 별도 검수 토큰이 있을 때만 getUser를 호출한다. 실제 Drive 읽기/쓰기 검수는 현재 probe가 수행하지 않으므로 별도 승인 자료 실행 증거가 필요하다.

## UTC와 원본 날짜

| 계약 | 구현 기준 |
| --- | --- |
| instant_storage | 시간 포함 필드는 timezone-aware datetime으로 받고 PostgreSQL timestamptz로 저장한다. API는 UTC ISO 8601 Z로 직렬화한다. 서버와 DB 세션 기준은 UTC이며 default now()도 timestamptz를 유지한다. |
| source_conversion | Asia/Seoul 원본 시각은 해당 timezone을 해석한 뒤 UTC로 변환한다. aware 시각의 tzinfo를 UTC로 바꾸는 재라벨링은 허용하지 않는다. |
| naive_input | 소스 계약이 Asia/Seoul을 명시한 입력에만 naive 지역시각을 허용한다. 계약 없는 입력·timezone/offset 불일치·잘못된 날짜·정밀도 정책 밖 입력은 사유와 함께 거절한다. |
| provenance | 필요한 소스 시각/원본 timezone/기준일/자료 버전을 별도 필드로 보존한다. timestamptz만으로 원본 timezone이 보존된다고 가정하지 않는다. |
| date_only | 모집요강의 시각 없는 날짜는 Python date/PostgreSQL date/ISO YYYY-MM-DD로 보존한다. 자정을 임의로 붙여 UTC 날짜로 이동시키지 않는다. |
| local_day_query | 서울 달력 날짜의 조회 범위는 [해당 날짜 서울 00:00, 다음 날짜 서울 00:00)을 UTC로 변환한다. UTC 날짜 문자열 비교로 서울 하루를 조회하지 않는다. |
| clock | 권한 만료·감사·리포트 발행·갱신/정렬은 UTC aware clock을 사용한다. 테스트는 주입 clock으로 만료 직전·동일시각·직후를 검수한다. |
| runtime | Windows/서버에서 IANA Asia/Seoul ZoneInfo 데이터가 존재하는지 확인하고 필요한 tzdata 의존성을 명시한다. |
| pooling | 접속/트랜잭션 경계에서 UTC 세션 정책을 보장한다. 연결 풀 재사용에서 세션 timezone이 바뀌어도 instant와 date가 바뀌지 않도록 검수한다. |
| precision | 소수초는 최대 6자리이며 7자리 이상을 조용히 반올림하지 않고 거절한다. |
