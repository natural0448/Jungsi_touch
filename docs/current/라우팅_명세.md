# 정시터치 화면과 API 라우팅 명세

이 문서는 공통 명세 service_spec.json에서 생성한다. 현재 버전은 1.2.0이며 기획·라우팅·계층 문서를 같은 변경으로 갱신한다.

화면 URL과 서버 API 계약을 같은 요구사항에 연결한다. 아래 API는 연결 예정 계약이며 HTTP 핸들러가 등록된 상태가 아니다. 기존 성적 엔진과 권한 기반 모듈을 연결할 때 이 계약을 따른다.

## 화면 경로

| 페이지 | 화면 | 경로 | 회원 | 역할 |

루트 /는 /admissions/results로 연결한다. 비회원의 1페이지 접근은 미정이며 현재 권한 기반의 기본값은 인증 필요다. 로그인된 일반·유료 사용자의 1페이지 접근은 성적 입력을 요구하지 않는다.

## 권한과 응답 경계

서버가 검증한 세션·현재 이용권으로 Actor를 만든다. 요청 본문의 회원등급·학생 ID를 신뢰하지 않는다. 미인증은 401, 일반가입자의 유료 요청은 403으로 차단하고 결과·건수·상세를 반환하지 않는다. 없는 리포트와 타인 소유 리포트는 같은 404로 처리한다. 본인 분석에 확인한 성적이 없으면 409와 보류 사유다.

권한 모듈은 HTTP 인증이나 응답 필드 제거 기능을 대신하지 않는다. 실제 핸들러에서 입력 검증, 운영 저장소 조회, 회원별 응답 객체, 분포·산식 승인 검사를 연결해야 한다. 학부모·상담자 위임은 아직 본인 권한으로 간주하지 않는다.

## 화면 표시용 본인 회원 등급

화면이 탭 잠금·이용 안내를 미리 표시하도록 서버가 판정한 본인 회원 등급을 돌려준다. 화면 표시용이며 각 API 의 권한 검사를 대신하지 않는다.

작업: session.read. 응답 필드: format, member_tier, entitlement_expires_at. 회원 등급 값: standard, paid.

- 미인증: 401 authentication_required — 화면은 비회원으로 표시한다
- 시각: entitlement_expires_at 은 UTC ISO 8601 Z 문자열이며 유료가 아니면 null. 화면은 Asia/Seoul 로 변환해 표시한다
- 화면 규칙: 화면은 이 응답을 잠금 표시에만 쓰고, 유료 화면의 실제 차단은 해당 API 의 403 을 따른다. 브라우저 저장값이나 요청 본문의 등급을 쓰지 않는다.

응답 제외: 학생 성적; 결제 수단·결제 내역; 다른 사용자 정보; 내부 이용권 ID·부여자.

## 2페이지 전체 분석 애플리케이션 계약

검증된 서버 Actor를 먼저 확인한 뒤 등록 시험과 자료 버전의 학생 성적을 기존 ExamPack으로 분석한다. 누적곡선의 부재·미승인·불일치는 전체 입력 오류가 아니라 overall.pending으로 반환하고 총점과 과목 결과를 보존한다.

서비스: jungsi_touch.application.overall_analysis.OverallAnalysisService.analyze

필수 입력: exam_id, pack_version, korean, math, inquiry. 선택 입력: english_grade, korean_history_grade.

- exam_id·pack_version은 등록 ID 토큰이며 파일 경로가 아니다
- 국어·수학은 standard_score와 선택적 choice만 허용
- inquiry는 서로 다른 두 과목의 subject·standard_score
- 점수·등급·선택과목 검증은 기존 시험 엔진에 위임
- 학생 ID·유료 플래그·자료 경로·research·승인 상태·동점 정책 입력은 거부

학생 응답: format, exam, pack_version, score_basis, total_standard_score, subjects, absolute_grades, overall. 과목 필드: area, subject, choice, standard_score, grade, top_percent_exclusive, top_percent_inclusive, basis. 누적 필드: status, reason_code, top_percent, inclusive_top_percent, exclusive_top_percent, tie_share_percent, tie_interval_percent, tie_policy, population_id, model_version.

누적 값은 0~100의 소수 문자열이며 내부 도수·가중치는 반환하지 않는다. include_equal; 포함/제외 값과 동점 구간도 표시. 동점 범위는 모형 신뢰구간이나 합격확률이 아님.

공급 포트: application.ports.ExamAnalysisProvider: get_exam_pack(exam_id), get_total_model(exam_id, pack_version). 총점 공급값은 서버 채택 distribution_id를 결속한 TotalModelBinding 또는 미발행 None.

| 누적 대기 코드 | 이유 |
| --- | --- |
| total_model_missing | 해당 시험·자료 버전의 총점 곡선 미발행 |
| total_model_unavailable | 총점 공급 자료를 읽거나 구성할 수 없음 |
| total_model_invalid | 공급 객체 또는 모델 계산 형식 불일치 |
| total_model_not_approved | 운영 승인되지 않은 총점 곡선 |
| model_version_mismatch | 서버 채택 분포 버전과 공급 모델의 분포 ID 불일치 |
| model_exam_mismatch | 학생과 총점 모델 시험 ID 불일치 |
| model_pack_mismatch | 공식 시험 자료 버전과 총점 모델 연결 불일치 |
| model_population_mismatch | 공식 유효 국수탐2 모집단의 인원 범위·확인 분모 불일치 |
| academic_year_mismatch | 학생과 총점 모델 학년도 불일치 |
| score_outside_domain | 입력 총점이 모델 검증 범위 밖 |
| model_not_ready | 계산 엔진 승인 검사 미통과 |

| 오류 코드 | HTTP 어댑터 상태 | 의미 |
| --- | --- | --- |
| authentication_required / invalid_server_context | 401 | 시험·곡선 공급자 호출 전 차단 |
| invalid_request / engine_input_code | 422 | 허용 필드 또는 해당 시험 성적 불일치 |
| pack_version_mismatch | 409 | 요청한 공식 자료 버전 갱신 필요 |
| exam_not_available / exam_data_unavailable / exam_binding_invalid | 503 | 유효한 시험 자료 공급·연결 미준비 |

응답 제외: 학생/리포트 소유자 ID; 대학 분석·환산·예측·추천; 분포 전체·도수·성별/동점 인원·가중치·정확 내부비율; 출처 로컬 경로·원문 전체·해시·연구 플래그·승인 필드.

HTTP·로그인·결제·영속 리포트 저장은 후속 feature가 연결한다. 일반과 유료에게 동일한 본인 입력의 전체 분석 DTO만 제공한다.

## 함께 생성하는 계약

화면은 apps/web/route_catalog.json을, 애플리케이션은 src/jungsi_touch/application/route_catalog.json을 사용한다. 두 파일과 이 문서는 공통 명세에서 생성하고 검사한다.

화면 담당은 별도 작업자이며 feature/presentation-*에서 작업한다. 현재 개발팀은 서버 API와 애플리케이션·데이터/인프라를 담당한다. [프레젠테이션 작업 인계](프레젠테이션_작업인계.md)에 담당·브랜치·연동 경계를 기록한다. 화면은 우리 서비스의 허용 API 결과만 이용한다. Google Drive API·폴더·토큰·전체 원자료에 직접 접근하지 않는다.
